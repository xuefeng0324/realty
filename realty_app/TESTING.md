# Realty App 测试方法

## 目标

测试必须能区分产品缺陷、数据异常和测试脚本过时。只截图不校验、打印错误但退出码仍为 0、依赖固定端口的脚本都不能作为发布门禁。

## 三层测试

### 1. 快速门禁（每次代码修改）

- `npm run type-check`
- `npm test`
- `npm run build:h5`
- `npm run test:e2e:core`

核心套件包含浅色/深色主题视觉审计：总览、设置、房源筛选、地图、房源详情、小区详情、学校和70城八个页面分别检查页面背景、卡片、标题、辅助文字、输入区域及全部可见按钮的颜色对比度，并输出16张截图到 `tests/e2e/artifacts/theme/`。同一批页面还会在320px宽度下检查页面横向溢出及非滚动区域按钮裁切。

核心套件还包含独立响应式布局审计，覆盖320×800手机、844×390横屏和768×1024平板三种视口。该审计检查页面整体横向溢出、非滚动区域交互控件裁切，以及宽度不足24px的异常交互区域。

内容缩放审计在420×900视口下分别使用125%和150%页面缩放，覆盖同一组8个关键页面，检查缩放后页面横向溢出、非滚动控件裁切和不换行交互文字截断。该测试用于近似发现系统显示缩放或大字体带来的布局风险，不替代Android/iOS真机字体缩放测试。
- `npm run test:coverage`（版本发布前记录业务代码覆盖基线）

核心 E2E 覆盖所有页面可访问、控制台错误、首页折叠与组合贷、主题持久化、数据健康、无效 ID、地图五图层及缩放聚合；同时严格验证城市切换、房源筛选/重置/详情跳转、学校搜索空态、70 城排序与趋势、深广网签口径，以及首页四个专业页签的全部功能卡和关键数据行。

### 2. 扩展回归（功能批次结束）

- `npm run test:e2e:extended`

覆盖小区五维指标、房源迷你指标、学校榜、地铁步行与规划收益、网签热力等稳定专项。

### 3. 历史全量（夜间或版本发布前）

- `npm run test:e2e:history`

历史运行器会把本轮结果写入 `tests/e2e/artifacts/history-summary.json`，包含总耗时、并发数、失败脚本，以及瞬时网络错误首次失败和重试结果。定时或手动 CI 会把这些信息同步到任务摘要，便于长期判断是否需要降低并发；业务断言失败仍然不会重试。

核心、扩展和历史运行器在启动任何浏览器脚本前都会等待 `E2E_BASE_URL` 返回成功状态，默认最多等待30秒，可通过 `E2E_READY_TIMEOUT_MS` 调整。服务未就绪会直接以明确错误结束，不占用瞬时网络错误重试次数。

跨端发布前除H5外还应运行 `npm run build:mp-weixin` 和 `npm run build:app`。安全区域回归需要同时检查横向页面边距、底部弹层，以及地图详情浮层是否避开原生TabBar和底部手势区域；构建通过只能证明语法和条件编译正确，仍不能替代真机视觉验证。

主测试工作流会在类型检查和覆盖率测试后依次构建H5、微信小程序和App。任何一个目标编译失败都会阻止合并，避免跨端问题延迟到手工发包阶段才被发现。

国家统计局房地产数据更新可运行 `python scripts/crawl_nbs_real_estate.py`。验证时必须确认脚本发现的页面标题包含“全国房地产市场基本情况”，来源为 `www.stats.gov.cn`，CSV期间、发布日期和五组核心指标与官方表1一致。

历史全量默认同时运行 4 个脚本，每个脚本最多 90 秒。资源受限或排查不稳定用例时可调整：

```powershell
$env:E2E_CONCURRENCY=2
$env:E2E_TIMEOUT_MS=120000
npm run test:e2e:history
```

历史脚本用于发现旧功能回归，但其中部分仍依赖首页早期展开结构或旧 CSV 静态路径。失败后应先判断是产品问题还是测试契约过时，不能直接为了绿灯修改产品。端口必须通过统一环境变量注入，历史脚本也不得自行覆盖测试地址。

## 编写规则

1. 使用 `E2E_BASE_URL`，禁止新增硬编码端口。
2. 发现问题必须设置非零退出码。
3. 优先使用稳定的 `data-*` 属性，不依赖第一个/最后一个元素。
4. 每次点击后验证结果状态或 URL，不能只验证按钮存在。
5. 同时监听 `console.error`、`pageerror` 和失败请求。
6. 无效 ID、空数据、极值输入、重复点击和刷新持久化必须有负向测试。
7. 地图至少验证图层状态、overlay 数量、缩放同步和跨城市残留。
8. 数据测试同时校验日期、行政区集合、非负值、来源链接和口径标签。

## 覆盖率口径

覆盖率只统计 `src/api`、`src/config`、`src/local`、`src/rules` 和 `src/utils` 下的业务 TypeScript。Vue 页面由 E2E 覆盖，构建产物、测试文件和纯类型声明不进入分母。当前先记录真实基线；在核心查询和状态模块补齐测试后，再设置不会阻碍合理重构的最低阈值。
