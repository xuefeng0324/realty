# v1.123.29 map-view / listing-filter 死样式与死 computed 清理

## 背景

v1.123.28 用「模板全文逐类比对」清掉了 dashboard 的 37 个零引用 scoped 类。本轮把同一方法扩到其他页面，先落两个已完整核验的页面：map-view 与 listing-filter。

**关键教训（本轮真实发生的错误）**：首轮扫描把 map-view 的 `price-low/mid_low/mid/mid_high/high` 判为死类并删除，但 `buildIntegrity.test.ts` 的 v0.12.0 门禁立刻红灯。复核发现 `priceLevelClass` 用模板字符串 `` `price-${level}` `` 动态生成类名——扫描器只比对模板文本，抓不到运行时拼接。进一步查证：`priceLevelClass`、`priceLevelText`、`selectedCommunity` 三个 computed 在模板里同样零消费（地图已改为聚合计数渲染），所以最终结论是「CSS 与 computed 一起退役」，而不是简单回滚。这类动态拼接必须逐个人工复核。
