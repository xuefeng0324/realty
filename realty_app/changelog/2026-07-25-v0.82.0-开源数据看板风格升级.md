# v0.82.0 开源数据看板风格升级

## 设计参考

调研了GitHub Vue Dashboard主题以及常见开源分析后台。没有直接复制某个模板，而是提取适合当前移动端数据产品的共同原则：有限内容宽度、清晰表面层级、紧凑指标网格、低饱和背景、统一圆角和少量强调色。

## 改动

- 桌面和平板内容最大宽度设为1180px并居中，避免卡片横向无限拉伸。
- 深色主题使用低饱和深蓝背景和轻量绿色、蓝色环境光；浅色主题统一为冷灰背景与白色卡片。
- 卡片统一圆角、边框和阴影，减少不同页面各自为政的视觉效果。
- 首页筛选区加入产品层级、数据可信度标识和统一控件容器。
- 900px以上视口的筛选项及指标采用四列网格，移动端仍保持原有自适应布局。
- 全国宏观数据卡使用轻量蓝色语义层级，与绿色操作色区分。

## 权衡

没有引入Vuetify、Element Plus等完整组件库，因为uni-app需要同时支持H5、小程序和App，桌面组件库会增加包体并带来跨端兼容成本。本次通过现有CSS变量完成视觉系统升级，容易回退，也不会改变数据或按钮逻辑。
