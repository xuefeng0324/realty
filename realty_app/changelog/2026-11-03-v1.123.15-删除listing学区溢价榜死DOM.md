# v1.123.15 删除 listing 学区溢价榜死 DOM

2026-11-03 · versionCode 350

## 背景

v1.122 首页收敛为新版壳（`.home-v122-shell`）后，壳层 CSS 对非壳层直子级 `display:none!important`，v0.17.0 接入的 `listing-school-premium` 卡（🏫 高学区评分房源）自此永久不可见，成为隐藏死 DOM。本轮将其实现全删，延续 v1.123.13（hospital-rank）/ v1.123.14（school-premium-rank）同一路径。

## 删除内容（dashboard.vue）

- **模板约 110 行**：均溢价 3 KPI、4 桶溢价分布、分区挂牌溢价 Top5、小区挂牌溢价 Top5、学区挂牌量 Top5 小区、高评分房源行（`data-card-key="listing-school-premium"` 整卡）
- `listingPremiumOverview` ref 与 `loadAll` 内 `getTopListingsBySchoolPremium` 调用
- `lspCitySummary` / `lspDist` / `lspDistrictTop` / `lspCommunityTop` / `lspCommunityByVolume` 5 个 computed
- `lpScoreClass` 函数（本卡删除后无消费者）
- `listingSchoolPremiumRanking` 整组 import（5 函数 + 4 类型）与 `queries.getTopListingsBySchoolPremium` / `ListingSchoolPremiumOverview` 引用
- ADVANCED_CARDS 与 data-tools 卡片管理清单 `listing-school-premium` 条目

## 一并删除

- **孤儿 e2e**：`tests/e2e/smoke_listing_premium.mjs`（断言隐藏 DOM 的卡行数、不在任何 suite，同 smoke_school_premium 先例）

- `spMedalClass` / `formatNum` / `.sp-medal-mini` / `.medal-gold` / `.medal-silver` / `.medal-bronze` / `.medal-flat-mini`：区涨幅榜（~L2006）与商业热度榜（~L3645）仍消费
