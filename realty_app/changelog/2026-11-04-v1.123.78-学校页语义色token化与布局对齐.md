# v1.123.78 · 学校页语义色 token 化与布局对齐

## 背景

在全页面截图审计（22 路由 × 明暗主题）的「细节打磨」轮次中，聚焦学校相关页面与 dashboard 标题，发现两处问题：

1. 学校详情页（`school-detail.vue`）存在大量硬编码语义色（成功/警告/危险/聚焦色及其透明变体），未走设计 token，导致明暗主题下色值与全局语义色体系脱节、局部色值重复定义；
2. 学校页（`school.vue`）教育统计 grid 有 5 项数据，第 5 项「幼儿园」独占左列而右列留空，视觉重心偏斜；
3. dashboard 标题残留装饰 emoji（`🔥`、`🏆`、`📉`），与全站「文字优先」的风格不一致。

## 真实问题与修复

### 1. `school-detail.vue` 硬编码语义色 → token

| 元素 | 旧硬编码 | 新 token |
|------|----------|----------|
| `.school-hero` 背景 | `rgba(34,197,94,.16)` | `var(--color-success-soft)` |
| `.profile-tag--success` 背景 | `rgba(34,197,94,.14)` | `var(--color-success-soft)` |
| `.profile-tag--success` 文字色 | `var(--color-primary)`（误用） | `var(--color-success)` |
| `.profile-tag--warn` 背景 | `rgba(245,158,11,.14)` | `var(--color-warn-soft)` |
| `.profile-tag--warn` 文字色 | `#d97706` | `var(--color-warning)` |
| `.score-ring` 默认边框 | `rgba(14,165,233,.22)` | `color-mix(in srgb, var(--color-focus) 22%, transparent)` |
| `.score-ring` 高分边框 | `rgba(34,197,94,.45)` | `color-mix(in srgb, var(--color-success) 45%, transparent)` |
| `.score-ring` 中分边框 | `rgba(14,165,233,.42)` | `color-mix(in srgb, var(--color-focus) 42%, transparent)` |
| `.score-ring` 低分边框 | `rgba(245,158,11,.42)` | `color-mix(in srgb, var(--color-warning) 42%, transparent)` |
| `.factor-fill` 渐变 | `linear-gradient(90deg, #0ea5e9, var(--color-primary))` | `linear-gradient(90deg, var(--color-focus), var(--color-primary))` |
| `.source-warning` 背景 | `rgba(245,158,11,.1)` | `var(--color-warn-soft)` |
| `.error-icon` 背景 | `rgba(239,68,68,.14)` | `var(--color-danger-soft)` |

其中 `.profile-tag--success` 文字色之前误用 `--color-primary`（与「成功」语义不符），一并修正为 `--color-success`。

`color-mix()` 在 `listing-detail.vue` 已使用过，是项目内已接受的模式。

### 2. `school.vue` 教育统计第 5 项跨列

新增 `.edu-cell--full { grid-column: 1 / -1; }`，让奇数项的最后一项（幼儿园）横跨两列，消除右列留白。

### 3. `dashboard.vue` 装饰 emoji 移除

- `🔥 全品类区级网签热度榜` → `全品类区级网签热度榜`
- `🏆 综合 Top 5` → `综合 Top 5`
- `📉 5Y+ LPR 走势 (近 36 月)` → `5Y+ LPR 走势 (近 36 月)`
