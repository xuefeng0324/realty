# v1.123.21 卡片管理清单 bug 修复 + 进阶区死脚本清理

## 背景

例行优化轮侦察发现两处问题：

1. **Bug**：data-tools 首页卡片管理清单 `DASHBOARD_CARDS` 中 `macro-lpr` 条目与卡面
   `data-card-key="macro-lpr-card"` 失配，导致该卡的显示/隐藏开关失效（toggle 写入的 key
   永远匹配不到 `isCardHidden('macro-lpr-card')`）。
2. **死条目**：清单 18 项中 7 项在 dashboard 无对应卡面（district-wangqian-rank /
   poi-commercial / school-top-filter-sort / bedroom-area-heatmap /
   orientation-floor-matrix / decorate-age-matrix / community-scatter），开关均为无效条目。
3. **死脚本**：dashboard.vue 内 v1.121.147 Batch 8 遗留的进阶分析区块脚本
   （ADVANCED_CARDS / advancedCardCount / toggleFeaturedMode / expandAdvancedCards /
   advancedExpanded / ADVANCED_EXPANDED_KEY）从未接入模板；真实精简/完整开关在
   settings.vue（`data-settings-featured-toggle`，写同一 `FEATURED_MODE_KEY`）。

## 改动

- `src/pages/data-tools/data-tools.vue`：`DASHBOARD_CARDS` 18→11，`macro-lpr` 修正为
  `macro-lpr-card`，删 7 个死条目；清单与卡面 `data-card-key` 一一对应。
- `src/pages/dashboard/dashboard.vue`：删除进阶区死脚本（约 34 行），保留
  `featuredMode` / `FEATURED_MODE_KEY` / `loadUiState`（壳层精简模式仍由设置页驱动）。
- `tests/dataToolsEntry.test.ts`：
  - 新增禁出现门禁：ADVANCED_CARDS/advancedCardCount/expandAdvancedCards/advancedExpanded/
    ADVANCED_EXPANDED_KEY/仪表盘本地 `function toggleFeaturedMode` 不再出现；
  - 新增全等门禁：DASHBOARD_CARDS 条目集合 === dashboard `data-card-key` 集合（11 项）；
  - 陈旧断言翻转：ADVANCED_CARDS 存在断言、`hot: true` ≥4、advKeyMatches ≥10 移除。
- 文档：FEATURE_CATALOG F-DASH-01 现状追加；README 版本表新增本行。
