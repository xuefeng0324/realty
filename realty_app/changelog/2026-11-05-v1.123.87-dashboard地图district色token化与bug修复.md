# v1.123.87 · dashboard 行政区域图 bug 修复 + 地图 district 硬编码色 token 化

## 背景

上一轮建议 token 化 dashboard 地图 district 多边形颜色。在检查地图区 CSS 时，意外发现一个真实 bug：`reloadDistrictMap()` 函数已定义但从未被调用，导致行政区域图卡片从不渲染。本轮同时修复该 bug 并完成地图 district 颜色 token 化。

## Bug 修复：行政区域图卡片从不渲染

`reloadDistrictMap()` 在 [dashboard.vue:2431](file:///E:/github/application/realty/realty_app/src/pages/dashboard/dashboard.vue#L2431) 定义，调用 `getDistrictMap(app.cityId)` 加载行政区多边形数据。但 `loadRankingAndDistrict()` 数据加载函数中只调用了 `reloadListingFreshness()`、`reloadSchoolDims()`、`reloadLpr()`，漏了 `reloadDistrictMap()`，导致 `districtMap.value` 永远为 null，地图卡片 `v-if` 条件永远不满足。

修复：在 `loadRankingAndDistrict()` 中 `reloadSchoolDims()` 之后补上 `await reloadDistrictMap()`。修复后 dashboard 正常显示 11 个行政区 polygon + 区名标签。

## 地图 district 硬编码色 token 化

| 选择器 | 属性 | 原值 | 新值 |
|--------|------|------|------|
| `.map-district-p` | fill | `rgba(186, 230, 253, 0.55)` | `color-mix(in srgb, var(--color-accent) 28%, transparent)` |
| `.map-district-p` | stroke | `#1e40af` | `color-mix(in srgb, var(--color-accent) 70%, #000)` |
| `.map-district-p:hover` | fill | `rgba(254, 215, 170, 0.7)` | `color-mix(in srgb, var(--color-warning) 35%, transparent)` |
| `.map-district-lbl` | fill | `#1e3a8a` | `color-mix(in srgb, var(--color-accent) 55%, var(--color-heading))` |
| `.map-marker-lbl` | fill | `#991b1b` | `color-mix(in srgb, var(--color-danger) 55%, var(--color-heading))` |

关键设计：district/marker 标签 fill 混入 `var(--color-heading)`（浅色近黑、深色近白），使深色模式下标签自动变亮可读，修复深色背景上深蓝色/红色标签不可读问题。
