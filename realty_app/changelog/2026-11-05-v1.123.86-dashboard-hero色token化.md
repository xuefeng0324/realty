# v1.123.86 · dashboard hero 深绿/青色系硬编码色 token 化

## 背景

v1.123.85 明确将 dashboard `.home-v122-hero` 深绿/青色系硬编码色留作下一轮专项处理。本轮将 hero 区 5 类硬编码色迁移到 `var(--color-primary)` 派生，使首页首屏在明暗主题下主色随品牌绿自动切换。

## 修复内容

### 1. hero 背景三层（`.home-v122-hero`）

| 层 | 原值 | 新值 |
|----|------|------|
| 径向青色光晕 | `rgba(94, 234, 212, 0.22)` | `color-mix(in srgb, color-mix(in srgb, var(--color-primary) 60%, #fff) 22%, transparent)` |
| 线性渐变起点 | `#063d35` | `color-mix(in srgb, var(--color-primary) 18%, #000)` |
| 线性渐变中点 | `#075f50` | `color-mix(in srgb, var(--color-primary) 33%, #000)` |
| 线性渐变终点 | `#087d6a` | `color-mix(in srgb, var(--color-primary) 50%, #000)` |
| 投影 | `rgba(4, 78, 67, 0.2)` | `color-mix(in srgb, var(--color-primary) 20%, transparent)` |

### 2. 品牌/eyebrow 文字（`.home-v122-brand`, `.home-v122-eyebrow`）

青色 `#7fffd4` → `color-mix(in srgb, var(--color-primary) 60%, #fff)`。

### 3. 城市/实时指示点（`.home-v122-city-dot`, `.home-v122-live-dot`）

| 属性 | 原值 | 新值 |
|------|------|------|
| 背景 | `#5eead4` | `color-mix(in srgb, var(--color-primary) 60%, #fff)` |
| 外发光 | `rgba(94, 234, 212, 0.14)` | `color-mix(in srgb, color-mix(in srgb, var(--color-primary) 60%, #fff) 14%, transparent)` |

### 4. 搜索框（`.home-v122-search`, `.home-v122-search-input`）

| 属性 | 原值 | 新值 |
|------|------|------|
| 阴影 | `rgba(0, 31, 27, 0.2)` | `color-mix(in srgb, var(--color-primary) 15%, transparent)` |
| 输入文字色 | `#12342f` | `color-mix(in srgb, var(--color-primary) 12%, #000)` |

### 5. 搜索模式激活态（`.home-v122-mode--active`）

文字色 `#ecfdf5` → `color-mix(in srgb, var(--color-primary) 10%, #fff)`。

## 保留

- hero 区白色半透明叠加层（`rgba(255, 255, 255, …)`）：在深绿背景上明暗主题均正常，保留
- dashboard 地图 district 多边形 `stroke`/`fill`（`#1e40af`/`#1e3a8a`/`#991b1b`）：地图数据可视化，保留
- map-view / map-analysis POI 标记色：数据可视化，保留
