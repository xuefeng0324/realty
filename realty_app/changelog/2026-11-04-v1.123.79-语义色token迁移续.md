## 修复内容

### 1. listing-detail 来源可信度标签

```css
.source-trust--real {
  background: rgba(34, 197, 94, 0.18);  →  var(--color-success-soft);
  color: var(--color-trend-down);
}
.source-trust--derived {
  background: rgba(245, 158, 11, 0.18);  →  var(--color-warn-soft);
  color: #fbbf24;                        →  var(--color-warning);
}
.derived-warning {
  background: rgba(245, 158, 11, 0.12);  →  var(--color-warn-soft);
  color: #fde68a;                        →  var(--color-on-warn-soft);
}
```

浅色模式下 `--color-warning: #b45309`（深琥珀）替代原 `#fbbf24`（亮琥珀），在 `--color-warn-soft`（浅琥珀底）上对比度从 ~1.8 提升到 ~4.5，可读性显著改善。

### 2. listing-filter 迷你维度条

```css
.minidim-fill-green {
  background: linear-gradient(90deg, var(--color-primary), #10b981);
  → linear-gradient(90deg, var(--color-primary), color-mix(in srgb, var(--color-primary) 60%, #fff));
}
.minidim-fill-orange {
  background: linear-gradient(90deg, #fbbf24, var(--color-warning));
  → linear-gradient(90deg, color-mix(in srgb, var(--color-warning) 60%, #fff), var(--color-warning));
}
```

红档 `.minidim-fill-red` 已用 `var(--color-trend-up)` / `var(--color-danger)`，无需改动。

### 3. 奖牌金色（data-tools + foundation）

```css
/* data-tools medal-gold */
background: linear-gradient(135deg, #fbbf24, var(--color-warning));
→ linear-gradient(135deg, color-mix(in srgb, var(--color-warning) 60%, #fff), var(--color-warning));

/* foundation rank-gold */
background: linear-gradient(135deg, #fbbf24 0%, #f59e0b 100%);
→ linear-gradient(135deg, color-mix(in srgb, var(--color-warning) 60%, #fff) 0%, var(--color-warning) 100%);
```

浅色模式 `--color-warning: #b45309`（amber-700）混 60% 白 → 富金色；深色模式 `--color-warning: #f59e0b`（amber-500）混 60% 白 → 亮金色。明暗主题均保持奖牌金属质感。
