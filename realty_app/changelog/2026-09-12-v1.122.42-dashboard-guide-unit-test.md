## 背景

`realty_app/src/utils/dashboardGuide.ts`（28 行）是首页「使用指南」banner
的显示状态判定函数。文档级注释里明确写了硬约束：

> 必须在 setup 同步读 storage，禁止先 true 再 onMounted 改 false——
> 否则首帧会画出浅色渐变卡，启动页关掉后上半截必闪白。

但 `tests/` 目录**没有 `dashboardGuide.test.ts`**——只有
`dashboardGuideFlash.test.ts`（测的是渲染时机，不测函数本身）。

如果有人未来把 `isDashboardGuideDismissed` 的 catch 删了、或把 JSON.parse
改成宽松写法，UI 白闪 bug 就会回归而**无门禁拦截**。

## 加的测试

`tests/dashboardGuide.test.ts`（9 tests，覆盖 8 个边界 + 1 个常量稳定性）：

1. storage 未设置 → 显示指南
2. storage 空字符串 → 显示指南
3. JSON 字符串 "true" → 隐藏指南
4. JSON 字符串 "false" → 显示指南
5. JSON 字符串 parse 失败 → 显示指南（catch）
6. boolean true → 隐藏指南
7. boolean false → 显示指南
8. getStorage 抛错 → 显示指南（catch）
9. `DASHBOARD_GUIDE_KEY` 常量稳定性（防止被误改导致用户「已关闭」状态丢失）
