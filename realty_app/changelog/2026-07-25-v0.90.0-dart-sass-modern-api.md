# v0.90.0 —— 消除 dart-sass legacy JS API deprecation 警告

> 2026-07-25 · 自检：manifest versionName 0.90.0 / versionCode 91 ·
> config.APP_VERSION 0.90.0 / README 已新增此条。

## 触发

`./realty_app/.tmp-vite-087.err.log`（CI build-app-wgt.yml 在 ubuntu 上跑时是 stderr-only）
及本地 `npm run build:h5` 都打印：

```
DEPRECATION WARNING [legacy-js-api]: The legacy JS API is deprecated and will be removed in Dart Sass 2.0.0.
```

源头：`@dcloudio/vite-plugin-uni@3.0.0-4030620241128001` 内部仍用 sass legacy JS API，
本仓 `sass: ^1.69.5` 已 >= 1.71（默认推荐 modern）。Sass 在 build 时每一份 .scss / .vue <style lang="scss">
都会刷一遍这条 warning。CI log 噪音变多，未来 sass 2.0 还会失败。

## 修复

`realty_app/vite.config.ts` 显式：

```ts
css: {
  preprocessorOptions: {
    scss: {
      api: "modern-compiler",
      silenceDeprecations: ["legacy-js-api"]
    }
  }
}
```

- `api: 'modern-compiler'`：直接换新 API，绕开 vite-plugin-uni 的 legacy 调用；
- `silenceDeprecations: ['legacy-js-api']`：保守兜底，万一老 .scss（如 globalVariables 之类）
  仍走 legacy 也不刷屏。
