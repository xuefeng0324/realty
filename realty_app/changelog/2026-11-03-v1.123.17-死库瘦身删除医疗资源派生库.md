# v1.123.17 死库瘦身续：删除 hospitalRanking 派生库

## 背景

v1.123.16 已删 `listingSchoolPremiumRanking.ts` 与 `hospitalGeoAnalysis.ts` 两个 only-自测死库；侦察时确认 `hospitalRanking.ts` 同样无 src/ 消费者（v1.123.13 删除医疗资源榜死 DOM 后失去唯一 UI 消费），本轮顺手清理。

## 删除清单

### 库文件
- `src/local/hospitalRanking.ts`（约 200 行）
  - 函数 ×8：`levelRank` / `summarizeHospitalByCity` / `summarizeHospitalByCityDistrict` / `getHospitalTopByLevelByCity` / `getHospitalByCityByType` / `getHospitalKeyFlagByCity` / `getHospitalByCityByDistrict` / `getHospitalCrossCityByDistrict`

### 测试
- `tests/hospitalRanking.test.ts`（9 用例，孤儿自测）

## 侦察依据

- `grep src/` 零 import `hospitalRanking` / `levelRank` / `CityHospitalSummary` / `CityDistrictHospitalSummary` / `CrossCityHospitalEntry`。
- listing-detail / community「周边医院」卡走 http `getCommunityHospitals`（后端 API），不经本地派生库。
- store 数据面 `snapshot.hospitals` 与 importer / seed 管道（`scripts/crawl_amap_hospital.py`）不受影响。
- buildIntegrity「医院清单完整性」断言针对 `static/seed/hospitals.csv` 文件本身，与派生库无关，保持不变。
