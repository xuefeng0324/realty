# v1.119.0 · 地铁规划弯曲系数落地 map-view

**日期**：2026-07-25
**类型**：UI 接入（复用 v1.114.0 派生）

## 背景

v1.114.0 已经写了 11 个 `metroPlanningGeoAnalysis` 函数（含 `getMetroPlanningGeoByCityCrossReference`
计算弯曲系数 actual/straight）。弯曲比高的线路 = 同样直线距离下实际更长 = 站点更多 / 拐弯更多
= 通勤覆盖广。本版本接入 map-view 的 metro 模式。

## UI 接入（map-view）

`realty_app/src/pages/map-view/map-view.vue` 在 metro 模式 legend 下新增 **"🌀 弯曲系数 Top 5"** 卡，
含：

- **5 条线路**（按弯曲比降序）
- 每个 row 展示：排名（蓝底圆）+ 线路名 + 实际/直线距离 + 黄色比值（如 1.42）

仅在 `mode === 'metro'` 时显示。

## 复用 vs 新派生

**复用 v1.114.0 全部 1 个函数**：`getMetroPlanningGeoByCityCrossReference()` 返回全部线路 CurvatureEntry[]，
前端按 cityId 过滤 + slice(0, 5)。

未新增派生函数，**未新增单元测试**（原有 13 个测试已覆盖 CrossCity + Haversine + edge cases）。
