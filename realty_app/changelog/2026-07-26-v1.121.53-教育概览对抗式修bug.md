# v1.121.53 — 教育概览对抗式修 bug（Hunter→Skeptic）

## 背景

采用「AI 找 bug」常见流程：先 **Hunter** 列可达缺陷候选，再 **Skeptic** 只保留可复现项，最后用回归测试把错误行为钉死。本版只修已确认的教育事业相关 P1/P2。

## 确认缺陷与修复

| 级别 | 问题 | 修复 |
|------|------|------|
| P1 | 仪表盘/学校页用异步 `cities`/`cityNameForId`，首屏可能得到 `city#id` → 教育卡不渲染 | 改用同步 `store.getCityById` |
| P1 | `educationOverview.ts` 用 `line.split(",")`，字段含逗号会错列 | 改用共享 `parseCSV` + `rowsToObjects` |
| P2 | 珠海 `period=2024` 被写成「2024 年」（实为学年） | `formatEducationPeriodLabel` → `2024–2025 学年` |
| P2 | 仪表盘深圳标签「中小学」与官方「普通中小学」不一致 | 文案对齐 |
| P2 | 广州/珠海学校页有小学/初中时隐藏幼儿园 | 分项城市仍展示幼儿园 |
| P2 | matrix 未覆盖教育卡 | school 页签增加「教育事业」+ `[data-education-overview]` |
