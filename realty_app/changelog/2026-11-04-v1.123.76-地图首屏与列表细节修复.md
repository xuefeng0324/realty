# v1.123.76 · 地图首屏与列表细节修复

## 背景

延续前两轮的视觉清理，本轮重点复查地图找房与列表类页面。验证过程中确认了两个影响可用性的真实 bug（首屏城市错位、底图永久空白），其余为跨页面单位/换行/朝向一致性等细节问题。

## 真实问题

1. **地图首屏城市错位**：App 默认城市是广州（`cityId=1`），但 `mapCenter` 硬编码深圳坐标（22.543, 114.06），首屏所有广州房源气泡都落在视口外，看起来「地图没有数据」。新增 `CITY_CENTERS`，按 `app.cityId` 初始化地图中心；`zoomToCity` 复用同一份坐标表，避免两处硬编码漂移。
2. **地图约 1/3 区域永久显示高德未加载网格**：实测窗口 resize、1px 高度微调均无效；Amap H5 只完整绘制「完整落在视口内」的区域。容器高度由 `80vh`（约 675px，超出视口）改为 `calc(100vh - 400px)` + `min-height: 300px`，地图完整铺满且不再出现网格占位。
3. **深色模式底图未加载区闪白**：高德 `.amap-container` 自带内联 `#f4f4f4`，与深色页面形成白块。`:deep(.amap-container)` 背景统一为 `--color-soft-strong !important`。
4. **图层/总价横向 chip 溢出卡片**：uni-app H5 的 `scroll-view` 宿主是 `overflow: visible`，chip 会画到卡片外，右缘渐隐也失效。宿主补 `overflow: hidden`，并保留 `map-mode-scroll--fade` 渐隐。
5. **同小区行朝向自相矛盾**：源标题可能写「…东南」，结构化 `orientation` 是「西」，同一行显示两个朝向。新增 `listingDisplayTitle(title, orientation)`，在存在结构化朝向时剔除标题末尾的朝向词；详情主标题、同小区列表、找房列表、小区页、地图 sheet 统一使用。
6. **单位与换行细节**：小区学校「最近 1000m」与列表「1.0km」不一致 → 统一 `formatDistance`；网签面积 6867㎡ 与 1.8万㎡ 混排 → 统一万㎡（保留两位有效）；供需 KPI「万㎡/亿元」在 3 格窄列换行 → 加 `nowrap` + compact；趋势分析 5 列年份表头 `2000-2004` 溢出卡片 → 压缩为 `2000-04`；找房空封面单字「房」被压成两行 → 改「暂无实拍」+ `flex:none`；5 维迷你条「性价比」换行 → 收紧 gap + label `nowrap`；地图分析区名与小区点重叠 → 小区模式加 chip 底色 + 碰撞阈值 8→14。
