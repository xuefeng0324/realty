## 改了什么

1. **派生函数（`src/local/stats70.ts`）**
   - `City12MonthSummary`：描述某城市近 12 月 / 前 12 月两个窗口 + 平均值 + drift。
   - `getCityDriftOverLastYear(base = "同比", kind = "second")` →
     消费已有 `stats_70.csv`，无需任何外部抓取。
   - `summarizeCityDrift(summaries)` → 把结果分成 expanding / contracting / unknown 三档，
     expanding 按 drift 降序，contracting 按 drift 升序。
   - drift = `(recentAvg - prevAvg) / prevAvg`；语义是「最近 12 月的同比 / 环比均值相对
     再之前 12 月的同比 / 环比均值，**正表示持续走强 / 负表示走弱**」。

2. **dashboard mini 卡（`src/pages/dashboard/dashboard.vue`）**
   - 新增「全国 70 城 · 近 12 月同比趋势」卡，三宫：
     - 扩张城市数（红色数字，因为指数走高常被视为价格压力）
     - 收缩城市数（绿色数字）
     - 数据不足（灰色）
   - 下方两列：扩张 Top 3 / 收缩 Top 3（城市名 + 索引 drift 百分比）
   - 一句来源说明："派生：最近 12 月指数均值 / 前 12 月指数均值 -1，数据源 stats_70.csv，仅二手指数"

3. **测试**
   - `tests/stats70Drift.test.ts` 6 个用例：
     * drift > 0 / < 0 / = 0 三个城市
     * summarizeCityDrift 排序
     * latest / latestDate 字段
     * 数据不足 24 月时 drift = null 不报错
