# v0.59.0 首页渐进式信息布局

发布日期：2026-07-25

## 问题

首页概览为了同时呈现区域、网签、通勤、小区、学校和利率信息，所有长列表与趋势内容默认完整铺开，导致移动端滚动距离过长。直接删除卡片或减少榜单行数会损失信息，因此本次采用渐进式展示。

## 参考模式

- Grafana Dashboard 的可折叠 Row：默认收纳长面板，需要时展开。
- Home Assistant Dashboard 的分视图导航：用短入口快速到达指定信息组。
- 常见管理后台的摘要卡 + 详情展开：首屏先展示关键结论，完整数据保留在原位置。

## 实现

- 将概览中的区域、网签、通勤、小区、学校和 LPR 标记为独立信息分组。
- 概览模式下每个分组限制摘要高度，底部渐变提示“展开完整数据”。
- 点击折叠卡时优先执行展开，不触发卡片内部的跳转或筛选按钮。
- 提供横向快捷导航，点击后展开指定分组并滚动到对应位置。
- 提供全部展开和全部收起按钮。
- 切换到价格、学校、通勤等专业 Tab 后取消概览高度限制。

## 兼容性

- 数据仍全部渲染，未减少任何榜单、趋势点或指标。
- 保留键盘 Enter 展开能力，折叠卡具有可聚焦状态。
- 浅色和深色模式继续使用统一主题变量。
