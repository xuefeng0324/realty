# v1.123.83 · 残留 UI 硬编码色 token 化 + 去除违规渐变

## 背景

v1.123.82 完成 sky-500 迁移后，继续全仓扫描残留硬编码 UI 强调色。发现两类问题：① 仍有 UI 控件使用硬编码色（`#f59e0b` 琥珀、`#6366f1` 靛蓝）未走语义 token；② dashboard 地图模式 tab 选中态使用靛蓝渐变，违反 v1.123.73 确立的「删除渐变主按钮 / UI 控件不使用渐变」设计规则。

## 修复内容

### 1. dashboard 地图模式 tab 选中态去渐变

`.map-mode-tab--active` 原使用靛蓝渐变，违反 UI 控件不使用渐变的设计规则，且与同类选中态 `wq-cat-tab-on`（已用 `var(--color-focus)`）不一致：

```css
.map-mode-tab--active {
  background: linear-gradient(135deg, #6366f1, #8b5cf6);  /* 靛蓝渐变 */
}
```

改为纯色 token，与 `wq-cat-tab-on` 对齐：

```css
.map-mode-tab--active {
  background: var(--color-focus);
}
```

### 2. dashboard 学区排名数字靛蓝 → focus

`.sd-rank` / `.sd-rank-sm` 排名数字文字色 `#6366f1`（indigo-500）→ `var(--color-focus)`。排名数字属 UI 强调元素，与 tab 选中态统一用 focus 色。

### 3. ProgressBar warn 填充 → warning token

`.progress-bar__fill--warn` 背景 `#f59e0b` → `var(--color-warning)`。ProgressBar 组件已有 `--primary`/`--accent` 变体用 token，warn 变体补全。

### 4. community 价格直方图中段 → warning token

`.bin-mid` 背景 `#f59e0b` → `var(--color-warning)`。同组 `.bin-high` 已用 `var(--color-success)`、`.bin-low` 已用 `var(--color-danger)`，中段对齐。
