# v1.123.74 · 散点空白修复与细节打磨

## 背景

用户在 v1.123.73 设计体系统一后继续反馈「很多地方功能正常但细节不到位、不美观」。本轮先修真实渲染 bug，再逐页清理视觉与文案细节，全部改动均通过构建、单测、E2E 与浅/深色截图复查。

## 真实 bug

1. **趋势分析散点图整块空白**：`useTrendVisualization.scatterImproveCohort` 返回的 y 仍是 `medianTotalPrice10w * 10000`（元），而散点归一化用的 `scatter.yMin/yMax` 以「万」为单位，导致 `bottom` 被算到约 203 万 px，所有点落在视口外。改为统一「万」单位后恢复显示。
2. **社区价格趋势出现大量空行**：近 12 周里无成交的周仍渲染成空条 +「—」，视觉上像坏掉；现在只保留有均价的周。
3. **网签周环比下降方向不明确**：`formatWowPct` 只返回绝对值，下降项仅靠颜色区分，`-52.8%` 实际显示为「52.8%」；分类趋势行与「周环比下降 Top」补上负号。
4. **小区挂牌龄中位数为负**：`compute_listing_freshness.py` 用固定 TODAY，早于部分房源 `crawl_date`，出现「中位挂牌龄 -74 天」；改为以 `listings.csv` 最大抓取日期为基准，重新生成 `listing_freshness.csv`。

## 地图分析可读性

- uni-app 会把模板里的 `<text>` 编译成 `<uni-text>`，写在 `<svg>` 内也不渲染，导致行政区名与数值全部不可见。改为 HTML 绝对定位文字叠层，保留 2 字简称，并按横向/纵向冲突自动错位避让。
- 色阶由「蓝→红」改为蓝色单色阶 + 图例，`fill` 通过内联 `style` 注入以正确读取 CSS 变量；无数据区显示「暂无样本」，明细不再堆叠重复数值。

## 视觉与文案细节

- **data-tools**：导航右缘加渐隐提示（可横滚）；卡片管理去掉英文 key，标签中文化；删除「Batch 1-6 / 派生层 / snapshot.* / CSV 文件名 / 公式」等工程术语；70 城趋势卡标题与「数据月」分两行。
- **trend-analysis**：散点补齐中位十字参考线、「总价 ↑ / 单价 →」轴标注，点色改用 `--color-accent` / muted / warning token，脚注改写为「横轴单价、纵轴总价」。
- **listing-filter**：流动性卡 meta 拆两行，消除「中位挂牌」孤字换行；「最最新鲜」→「最新鲜」、「最积压」→「挂牌最久」。
- **macro-rates**：日期范围改为 oldest ~ newest；明确「红 = 利率上行、绿 = 利率下行」；5 年期 LPR 与最长未调息拆行展示。

- **listing-detail**：去装饰 emoji、去「样本库/封面 URL」术语、周边 POI 图标改文字胶囊网格、紫色渐变改蓝、抓取日期改「数据日期」。
