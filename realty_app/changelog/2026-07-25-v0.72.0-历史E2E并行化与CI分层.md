# v0.72.0 历史 E2E 并行化与 CI 分层

## 变更

- 重写历史 smoke 全量运行器，以异步工作池受控并行执行 52 个独立脚本，默认并发数为 4。
- 每个脚本继续使用独立 Node 子进程和 Playwright 浏览器上下文，避免共享 localStorage、页面状态或城市筛选。
- 新增 `E2E_CONCURRENCY` 配置并发数，新增 `E2E_TIMEOUT_MS` 配置单脚本超时；非法值自动回退到安全默认值。
- 单脚本输出设置内存上限，正常通过只报告状态与耗时；失败时输出原因及末尾 20 行诊断信息。
- 新增 `npm run test:e2e:history` 标准命令，并在 `TESTING.md` 补充资源受限环境的运行方式。
- CI 设置与静态服务器一致的 `E2E_BASE_URL=http://127.0.0.1:5173`。
- Pull Request 执行核心 8 项和扩展 7 项套件；定时及手动工作流额外执行历史 52 项全量套件。

## 验证

- `node --check tests/e2e/_all_smoke.mjs`：通过。
- `npm run test:e2e:history`：52/52 通过。
- 并行总耗时 172.9 秒；原串行总耗时 660.7 秒，缩短约 74%。
- 未发现截图写入、浏览器上下文、城市状态或端口竞争导致的不稳定失败。
