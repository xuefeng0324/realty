# v1.123.3（versionCode 338）· 数据工具页锚点分组导航

日期：2026-11-03

## 背景

数据工具页（`pages/data-tools/data-tools`）Batch 1-6 共迁入 16 张派生卡 + 顶部卡片管理 + 尾部提示卡，页面长达十余屏，想看中后段的卡（如网签热度榜、学区评分 Top）只能一直手滑，定位困难。上一轮建议第 3 条：加锚点分组导航。

## 变更

### data-tools.vue

- **模板**：页头下新增吸顶横滚导航 `[data-dt-nav]`（`scroll-view scroll-x`，map-view 同款模式）：
  - 前置 ⚙️ 卡片管理 chip（滚回页顶管理卡）；
  - 17 张卡（Batch 1-6 迁入 16 张 + 页内原有行政区划卡）按语义分四组「市场（70城趋势/分区均价/网签热度/行政区划）· 交通（步行可达/步行通勤/规划受益/规划地铁）· 学区（教育事业/区情画像/学校指标/重点学校/学区Top）· 挂牌（挂牌结构/特征溢价/挂牌标签/标签组合）」，组间竖线分隔 + 组名小字；
  - 每个 chip 带 `data-dt-nav-item="<anchor>"`，点击 `scrollToDtCard(anchor)`。
- **滚动定位**：自算 `window.scrollTo`（H5 分支，`typeof document !== "undefined"` 守卫，dashboard `setDashTab` 同款模式）：
  - 实测 `@dcloudio/uni-h5` 的 `pageScrollTo` 只解构 `{ scrollTop, selector, duration }`，**`offset` 不透传**（uni-shared `scrollTo` 内部只减 `uni-page-head` 高度）→ 吸顶导航会盖住目标卡顶部；
  - 故 H5 端自行计算：`卡顶 − uni-page-head 高 − 吸顶导航高 − 8px 呼吸位`，`behavior: "smooth"`；
  - 非 H5 端回退 `uni.pageScrollTo({ selector, duration })`；
  - 目标卡无数据（v-if 未渲染）时 `uni.showToast({ title: "该卡片暂无数据" })`，不静默失败。
- **样式**：`.dt-nav` `position: sticky; top: var(--window-top, 0px)`（uni-h5 按页设置该变量 = 默认导航栏 44px + safe-area，吸顶恰好在 uni-page-head 下方）；负 margin 撑满 container 内边距；chip 复用 `--color-soft`/`--color-primary` 主题变量，深浅主题自适应。
