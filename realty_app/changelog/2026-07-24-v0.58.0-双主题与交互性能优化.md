# v0.58.0 双主题与交互性能优化

发布日期：2026-07-24

## 背景

此前页面以深色硬编码为主，没有可持久化的主题设置。切换到浅色环境时，页面背景、卡片、文字和按钮容易出现明暗混搭。同时首页存在 Tab 页面跳转方式错误，内存查询也会在每次视图计算时重复扫描房源数组。

## 变更

- 新增主题工具，支持跟随系统、浅色和深色三种模式。
- 统一全局颜色令牌、卡片层级、表单控件、弹层、按钮按压和禁用状态。
- 设置页新增外观切换入口，并同步导航栏与底部 TabBar 颜色。
- 首页“数据设置”快捷入口改用 `switchTab`。
- 修复政府在线查询说明错误输出对象 JSON。
- `setSnapshot()` 时建立城市、小区和房源索引，常用查询从重复数组扫描改为 Map 读取。
- 朝向×楼层、装修×楼龄矩阵的城市中位价改为加权中位数计算，不再按 `count` 展开临时数组。
- 新增主题解析单测和 Tab 页面导航完整性测试。

## 兼容性与风险

- 主题选择默认跟随系统，原深色用户在深色系统下视觉保持不变。
- H5 可完整动态切换主题；App 与小程序同步导航栏和 TabBar，页面主体使用同一套全局令牌。
- 内存索引在快照替换时重建，会增加少量常驻 Map 内存，换取查询阶段更稳定的性能。
