# v1.121.96 — 地图挂牌均价可读与验收

## 问题

用户反馈：地图找房点「挂牌均价」后地图黑乎乎；质疑测试用例是否覆盖 UI 与功能逻辑。

## 根因

1. **图例 `formatPriceRange` 算错**：对已 `/1000` 的值再 `/1000` → 全表显示 `0k-0k`
2. **price 模式给无均价社区铺不透明灰圆**：52 小区仅少数有价时，大量灰圆糊死底图
3. **`fillColor` 用 `rgb()`**：App 端 `<map>` circles 常要求 8 位 hex，失效易变黑灰
4. **价格归一化运算符优先级错误**：半径计算未先减后除
5. 地图容器无浅色占位 → 加载前透出深色 page

## 改动

- `mapMath.ts`：热力/分位/图例/色阶单一来源；8 位半透明 hex
- `map-view.vue`：price 只画有价社区；浅色 map-wrap；主题化 info-card
- `MAP_ACCEPTANCE.md`：对照贝壳/Google Maps/Mapbox，Given-When-Then × UI/功能/逻辑
- 门禁：`mapMath.test.ts` 扩写；`smoke_price_heatmap` 断言非 0k-0k + 占位亮度

## 验收

- unit 923 通过；真机：挂牌均价须能辨认道路 + 图例非 0k-0k
