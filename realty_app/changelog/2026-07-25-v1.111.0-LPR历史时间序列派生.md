## 背景

`LocalLprRow` 自 v0.53 起就接入了全链路（types / importer / snapshotLoader / store），
但 0 个派生函数消费它。LPR 数据是**金融时间序列**的典范——4 个利率（LPR 1y / LPR 5y
/ 首套 / 二套）跨 7 年，可派生：

- **调息周期**（lpr5y 变化的所有节点 + 方向 + 累计幅度）
- **降息累计**（自 2019 起点累计降息幅度 bp）
- **当前快照**（最新一行的 4 利率 + vs 1 年前对比）
- **首套/二套 vs lpr5y 利差**（"加点"变化时间线）

## 12 个派生函数

| 函数 | 作用 | 价值场景 |
|------|------|----------|
| `getLprLatest` | 最新一行快照 | "当前 LPR 5y = 3.5%" |
| `getLprAtMonth(month)` | 单月精确查询 | "2024-10 降息当月 LPR 是多少" |
| `getLprByYear(year)` | 单年所有月（升序） | "2024 年 12 个月 LPR 走势" |
| `getLprRange(min, max)` | 区间全部行 | "2024-12 ~ 2025-06 LPR 走势" |
| `getLprDelta(from, to)` | 区间累计变动 bp（4 利率） | "过去 1 年 LPR 5y 降 70bp" |
| `summarizeLprCurrentVsYearAgo` | 当前 vs 1 年前 bp 对比 | "过去 12 个月利率变化" |
| `summarizeLprByYear` | 年聚合（年初/年末/最大/最小/调息次数） | "2024 年 2 次降息，2025 年 1 次降息" |
| `detectLprCutCycles` | 自动检测 lpr5y 所有调息节点 + 方向 + 累计 bp | "7 年累计降 135bp（5 个降息节点）" |
| `getLprLongestFlatStreak` | 最长连续未调息月数 + 起止月 | "2020-04 ~ 2021-12 共 21 个月未调息" |
| `summarizeLprSpread` | 首套/二套 vs lpr5y 利差时间线 + 当前利差 | "当前首套 -30bp（折扣），二套 +35bp" |
| `getLprDownwardCumulative` | 自起点累计降息 bp（4 利率） | "2019-08 → 2026-06 累计降 135bp" |
| `getLprMonthlyAverage` | 全期 lpr5y/lpr1y 平均 | "7 年 LPR 5y 平均 4.07%" |

## 关键决策

1. **bp 统一在派生层转换**：1% = 100bp。所有"降幅"派生返回 int bp 而非 float%，
   UI 直接展示 `+70bp` 比 `+0.7%` 更醒目。
2. **降息定义为正 bp**：`changeBp = (prev - cur) * 100` → 降息为正，加息为负。
   与中文金融语义一致（"降 70bp"）。
3. **方向枚举**：`"down" / "up" / "flat"` —— 历史无加息事件，故 flat 实际不用，
   但保留未来扩展（万一 PBOC 加息）。
4. **`getLprLongestFlatStreak` 算法修正**：第一版只在循环内更新 best，
   漏掉了"末尾非变"窗口；改成"变化时比较 + 循环后再比较一次"，
   覆盖所有边界。
5. **`summarizeLprSpread` 利差定义**：
   - `firstSpreadBp = (mortgageFirst - lpr5y) * 100` → 负数 = 折扣（首套打折）
   - `secondSpreadBp = (mortgageSecond - lpr5y) * 100` → 总是正数（二套加点）
   - `firstSecondDeltaBp = (mortgageSecond - mortgageFirst) * 100` → 二套 vs 首套差额
