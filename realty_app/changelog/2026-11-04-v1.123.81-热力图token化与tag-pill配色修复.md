# v1.123.81 · 热力图色阶 token 化 + tag-pill 配色修复 + 地图空区域主题适配

## 背景

落实 v1.123.80 建议清单中遗留的三项：trend-analysis 热力图蓝色阶、dashboard 地图空区域填色、以及审计中发现的 listing-filter tag-pill 配色不匹配 bug。

## 修复内容

### 1. trend-analysis 热力图色阶 token 化

`户型 × 面积分布` 矩阵 `.ba-cell` 三档蓝色阶硬编码 → 语义 token：

```css
.ba-cell--light { background: #eff6ff; }      → var(--color-info-soft)
.ba-cell--mid   { background: #bfdbfe; }      → color-mix(in srgb, var(--color-accent) 35%, #fff)
.ba-cell--deep  { background: #1d4ed8; }      → var(--color-accent)
```

- 浅色模式 `--color-accent: #2563eb`（blue-600），deep 由 #1d4ed8 → #2563eb（同色系微调）
- 深色模式 `--color-accent: #1d4ed8`（blue-700），deep 精确匹配原值
- light/mid 由 accent 派生，深浅主题各自适配
- 文字 `#0f172a`（slate-900）保留：浅蓝底需深色文字，无对应「始终深色」token，属数据可视化常量

### 2. listing-filter tag-pill 配色 bug 修复

```css
.tag-pill {
  background: rgba(37, 99, 235, 0.12);  /* blue-600 软底 */
  color: var(--color-primary);          /* green 文字 */
}
```

蓝色背景配绿色文字，颜色语义不匹配。修复为绿底绿字一致：

```css
.tag-pill {
  background: var(--color-primary-soft);
  color: var(--color-primary);
}
```

### 3. dashboard 地图空区域主题适配

`districtFill()` 在 marker 模式或无数据时返回 `#f1f5f9`（slate-100），深色模式下空区域呈亮灰色块。迁移为 `var(--color-panel-soft)`（浅色 `#f1f5f9` 精确匹配，深色 `#162033`）。SVG `fill` 属性原生支持 CSS `var()`。

## 保留

- `#0ea5e9`（sky-500）：跨 dashboard/data-tools/wangqian 4 页一致使用的强调色，无对应 token，保留。
- 地图数据可视化色阶（`districtFill` 的绿→黄→红色阶）、`mapMath.ts` 价格色阶：数据可视化，保留。
- trend-analysis `ba-cell` 文字 `#0f172a`：数据可视化固定深色字，保留。
