# v0.71.0 政府链接与历史 E2E 契约收敛

## 变更

- 政府链接流程测试由 4 个扩展到 8 个，覆盖内嵌 WebView 地址与标题编码、系统浏览器模式、预售登录确认/取消，以及 App 自动模式优先系统浏览器。

- 散点与详情钻取测试进入价格专业 Tab 后验证，返回 Dashboard 后重新恢复对应测试上下文。
