# v1.102.0 网签周趋势派生（仅数据层）

## 目标

复用既有 v0.10.0 完整链路（`wangqian_district_weekly.csv` → `LocalWangqianDistrictWeekly` → snapshot，60 行 × 4 周），新增 5 个高阶派生函数，让"周度网签变化"在数据层就绪。

## 数据

`wangqian_district_weekly.csv`（60 行）

| 字段 | 含义 |
|---|---|
| city | 广州 / 深圳 / 珠海 |
| district | 区 |
| category | 新房 / 二手 / 其他 |
| week_end | 周日（YYYY-MM-DD） |
| days | 该周实际有数据的天数 (3-7) |
| total_units | 累计成交套数 |
| total_area_sqm | 累计成交面积 |
| avg_daily_units | 日均套数 |
| avg_daily_area_sqm | 日均面积 |

## 派生

`src/local/wangqianTrendRanking.ts`（5 函数）：

1. `summarizeWangqianWeeklyByDistrict` —— 按 (city, district, category) 聚合：周数 / 累计 units / 平均日 units / 最新周 units / 最新周 weekEnd
2. `getWangqianWeeklyWoWChange` —— 周环比 WoW（最近 vs 前一周），输出 changePct；prev=0 且 latest>0 时为 `+Infinity`
3. `getWangqianWeeklyVolatility` —— 变异系数 CV = stdDev / mean；越接近 0 越稳定
4. `getWangqianWeeklyRecentSpikes(lookbackWeeks, minMultiplier)` —— 检测"最近一周较前 N 周平均突增 X 倍"的区，用于捕捉开盘 / 政策刺激 / 学区房集中过户等异常
5. `getWangqianWeeklyByCityCategoryTrend(lookbackWeeks)` —— 按 (city, category) 整市 trend：最近一周 vs 前 N 周平均
