# v1.121.95 — 浅色模式一眼可辨修复

## 问题

用户反馈：设置里选「浅色」后与未选差别不大，质疑验收标准与竞品对照。

## 根因

1. App WebView 上仅靠 `page[data-realty-theme=light]` 选择器时，CSS 变量经常不级联，页面仍用默认深色 token。
2. 首页 `stats70-card` / `wangqian-card` 硬编码 `#0c1426` / `#0c1a2e` 深色渐变终点，浅色切了表面仍发黑。
3. 多处把 `--color-soft`（背景色）误当文字色，浅色下近白字贴白底。

## 改动

- `themeTokens.ts`：浅/深 token 单一来源 + 相对亮度门禁（对照 MD3 / Apple HIG / 微信·贝壳「浅底深字」）
- `theme.ts`：`paintDom` 对 `html/body/page` **内联 setProperty('--color-*')** + class `realty-theme-*`
- `App.vue`：扩大浅色选择器，强制浅底；浅色分数胶囊改深字
- `dashboard.vue`：卡片渐变改 `var(--color-panel)`；修正 soft 当字色
- `THEME_ACCEPTANCE.md`：补竞品对照 + 「1 秒能认出浅色」合格线 + 亮度硬门槛
- 门禁：`themeTokens.test.ts`、`themeHardcodeGuard.test.ts`；smoke 亮度门槛提高到 0.85 / 差 ≥0.7

## 验收

- unit：`theme*.test.ts` 通过；全量 `npm test` 通过
- 真机：设置 → 浅色后内容区必须一眼浅灰白底深字（见 THEME_ACCEPTANCE A1）
