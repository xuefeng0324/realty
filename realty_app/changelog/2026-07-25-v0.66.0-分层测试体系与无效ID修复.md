# v0.66.0 分层测试体系与无效 ID 修复

## 变更

- 将 E2E 分为快速核心、扩展专项和历史全量三层。
- 新增实时输出的测试组执行器，统一六种历史环境变量到同一个测试地址。
- 修复旧全量汇总器把退出码为 0 的脚本误判为失败的问题。
- 全页面测试遇到页面或控制台错误时现在会真正失败。
- 边界测试遇到断言问题时现在会返回非零退出码。
- 不存在的房源和小区改为中文“未找到”提示。
- 新增 `TESTING.md`，固定按钮、地图、数据真实性和负向场景的测试要求。
- 覆盖率统计排除构建产物、测试脚本和纯类型文件，只统计业务 TypeScript，避免虚假低覆盖率。

## 背景

历史51个脚本首次统一执行时只有8个被旧汇总器认定通过，失败中混有硬编码端口、首页结构变更和错误的成功判定。新体系先保证核心门禁可信，再逐步迁移历史专项，避免测试数量很多但不能可靠阻止回归。

## 验证结果

- 核心门禁：6/6 组通过。
- 扩展专项：7/7 组通过。
- 全页面：12/12 可访问，控制台与页面错误均为 0。
- 单元测试：469/469 通过。
- 业务 TypeScript 覆盖率基线：语句/行 67.41%，分支 64.42%，函数 62.26%。
