# v1.121.4 — OTA 热更新验证与优化

## 背景

整包 APK（`realty.app` / versionCode 124）已可安装。远程 OTA 清单亦为 124，真机「检查更新」会显示已是最新，无法验证热更新。同时离线 SDK 5.15 与 cli 4.36 会弹版本不匹配框。

## 改动

1. **升版**：`1.121.4` / versionCode `125`，供 124 基座拉 wgt 验证。
2. **`compatible.ignoreVersion: true`**：关闭 HTML5+ Runtime 版本提示。
3. **OTA 优化**
   - 清单 URL 加 `?t=` 缓存戳，避免刚 push 后 CDN 吐旧清单
   - `UPDATE_BASE_URL` 改为 `raw.githubusercontent.com`（JSON 稳）
   - `buildWgtUrlCandidates`：固定 gcore → fastly → cdn → b-cdn
   - 安装成功后弹窗可「立即重启」（`plus.runtime.restart`）
   - CI 写入的 wgt URL 改为 gcore.jsdelivr
4. **设置页关于**：文案改为「热更新通道已开」，便于肉眼确认 OTA 生效。
5. 包名保持 **`realty.app`**（与 DCloud 后台 / 历史 APK 一致）。

## 真机验证步骤

1. 手机已装 versionCode **124** 整包
2. 本版本 push 后等 CDN 更新（通常 1～3 分钟；raw 更快）
3. 设置 → 检查更新 → 应提示 **v1.121.4（125）**
4. 下载安装 → 立即重启
5. 关于页应显示 `v1.121.4 · … · 热更新通道已开`
