## 关键改动

### 1. 新增 `src/components/MacroKpiCell.vue`

单 KPI 单元格组件，4 个 prop：

- `label: string`
- `value: string`
- `sub?: string`（可 slot 覆盖）
- `subTrendClass?: "up" | "down" | "flat"`（自动加 `stats70-*` 前缀）

模板用 `<view class="stats70-cell">` 三层结构，对原视觉零影响。

### 2. 新增 `utils/format.ts` → `macroTrendBand(v)`

与 `macroTrendClass(v)` 同源，输出简化为 `up | down | flat`，供 `MacroKpiCell` 接收。
dashboard 把原来的 6 处 `trendToBand` 改名为 `macroTrendBand`。

### 3. `dashboard.vue` nbs-macro 卡 16 个 KPI 改用 `MacroKpiCell`

涵盖 5 组 stats70-grid：
- 主 4 KPI（开发投资 / 新房销售额 / 新房销售面积 / 商品房待售）
- 房屋施工 / 新开工 / 竣工 / 到位资金
- 住宅施工 / 住宅新开工 / 住宅竣工 / 住宅施工占比
- 住宅销售面积 / 住宅销售额 / 住宅待售 / 住宅投资
- 国内贷款 / 定金及预收款 / 个人按揭贷款 / 自筹资金

每组 4 KPI × 5 行 HTML → 4 行组件引用，**单组省 ~12 行 × 5 组 = 60 行**。

### 4. 删除 nbs-macro 多期序列 8 个细分 v-for 块

原 14 个 v-for → 保留 6 个核心（均价 / 可售月 / 面积同比 / 销售额同比 / 投资同比 / 资金同比）；
删除 8 个细分（施工 / 新开工 / 竣工 / 住宅施工 / 住宅新开工 / 住宅竣工 / 住宅面积 / 按揭 /
定金 / 国内贷款同比）。**省 32 行**。

### 5. 新增 `tests/macroKpiCell.test.ts`

3 个用例：组件 prop 完整性 / 模板三层结构 / dashboard import + ≥ 12 处使用。

### 6. 更新 `docs/DASHBOARD_OVERVIEW_BUDGET.md`

新增 §7「用户待拍板」+ §8「后续瘦身 todo（T-001 ~ T-006）」+ 本轮收益表。
