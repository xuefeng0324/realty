# v1.121.32 — 修 OTA 升级弹窗闪烁

**日期**：2026-07-26  
**versionName**：1.121.32 · **versionCode**：153

## 问题

启动检查升级可用，但点「立即更新」后进度弹层一闪一闪（反复出现/被关掉）。根因是下载 `statechanged` 高频回调里每次都 `uni.showLoading(...)`，Android 原生 loading 会被反复销毁重建。

## 修复

1. 新增 `createDownloadProgressUi`：App-Plus 优先 `plus.nativeUI.showWaiting` + `setTitle`，否则降级 `uni.showLoading`
2. `createThrottledProgressHandler`：有总量时仅整数百分比变化才刷新 UI
3. 启动弹窗延后 1.2s，避开开屏/首屏抢焦点导致的「发现新版本」闪一下又没
4. 安装完成后短暂延迟再弹「更新已安装」，避免与 hideLoading 抢焦点

## 验证

- `npm run type-check` 通过
- `tests/appUpdate.test.ts` 12/12 通过
- E2E / 真机：需 OTA 到 153 后手动点一次升级确认弹层稳定
