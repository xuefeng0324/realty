# e2e：4 个陈旧 extended 测试适配 v1.122 壳层（2026-11-03，不发版）

仅 `tests/e2e` 改动，按 VERSIONING.md 不 bump 版本。extended 组 4/8 → 8/8。

## 根因

v1.122 首页改版为纯壳层：`.home-v122 .container > :not(.home-v122-shell):not(.sheet-mask) { display: none !important }`
把旧长页全部分析卡隐藏（`.card[data-tab]` 的 F-DASH-04 tab 过滤之上又加了一层），
依赖「dashboard 可见卡片 + `.picker-value` / `.form-row` 旧选择器」的 4 个 extended 测试因此全挂：

| 测试 | 旧失败模式 | 目标卡现状 |
|------|-----------|-----------|
| smoke_metro_walk | 等 `.picker-value` 30s 超时 | 已迁数据工具页 `[data-dt-commute-walk]` |
| smoke_metro_benefit | 同上 | 已迁数据工具页 `[data-dt-plan-benefit]` |
| smoke_school_community | 卡标题 23 次 resolved hidden | 仍在 dashboard DOM 但 CSS 隐藏（待迁移） |
| smoke_wangqian_heatmap | 45 个 `.trend-row/.wq-row` resolved hidden | 同上 `[data-card-key="wangqian-rank-4w"]` |

## 改写方案

1. **metro 两个** → 改打数据工具页。切城不再写 localStorage（实测 uni H5
   存储不读裸 `localStorage.setItem`），改为 dashboard 壳层**真实 pickCity
   交互**（`[data-home-city]` → `.sheet-item`）→ hash 导航到数据工具页 →
   **`reload` 强制全新加载**（uni-app H5 缓存已挂载页面，onMounted 不重跑，
   直接 hash 往返会拿到上一个城市的旧数据）。断言保留原语义：行数/徽章/
   颜色分档/summary/广深 top1 不同。
2. **school / wangqian 两个** → 卡在 dashboard 仍有数据价值（待迁移清单内），
   改为 `attached` 断言验证数据层渲染（行数、Top1、`评分 \d+\.\d` 格式、
   深圳区名真实性、金牌），切城走真实 pickCity；截图前用
   **内联 `display:block !important`** 临时取消隐藏再对卡片元素截图
   （scoped CSS 给隐藏规则追加 `[data-v-hash]` 提高优先级，addStyleTag
   覆盖不稳，内联样式优先级最高最稳）。
3. 4 个文件 BASE 统一读 `REALTY_E2E_BASE_URL || E2E_BASE_URL || 5174`，
   截图统一落 `realty_app/screenshots/`。
