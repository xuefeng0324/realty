# v0.93.0 — 分区近 12 周均价变动（dashboard mini 卡）

日期：2026-07-25

## 目标

dashboard 已经能看「城市级同比（v0.91.0）」和「地铁可达性（v0.92.0）」，但还缺**分区级**视角——「广州天河 vs 海珠 近 12 周均价是涨是跌？」「最近 4 周仍在加速涨还是开始减速？」

v0.93.0 把已有的 `district_trend.csv`（269 行 = 15 区 × ~27 周）派生出**两个排行榜**：

- 「近 12 周 vs 12 周前」变化率（涨跌比例 + 末周 + 涨跌计数）
- 「近 4 周 vs 前 4 周」动量（是否在加速）

两条都是完全派生，**零抓虫、零外部依赖**。

## 数据源

| 字段 | 用途 |
|------|------|
| `static/seed/district_trend.csv` | 269 行分区 × 周度均价 / 中位价 / 挂牌数 |
| `local/types.ts` 的 `LocalDistrictTrend` | 一对一消费，无新表 |
| `local/store.ts` 的 `getDistrictTrends()` / `getDistrictTrendByDistrict()` | 已暴露，直接复用 |

## 关键改动

### 1. 新增 `src/local/districtDrift.ts`

三个公开函数：

- `getDistrict12WeekChangeRank(cityId?)`  
  按 (cityId, districtName) 分组排序，如果周数 ≥ 12 取 `arr[arr.length - 13]` 作基准，否则取 `arr[0]`，返回按 `change` 降序的 `DistrictChangeEntry[]`。

- `getDistrictRecentMomentumRank(cityId?)`  
  同上分组，最近 4 周均价均值 / 前 4 周均价均值 − 1，得 `momentum` ∈ [−1, +∞)；不足 8 周的项放 `momentum: null` 沉底。

- `getDistrictPriceSummary(cityId, districtName, recentWeeks=12)`  
  单分区摘要，dashboard 不直接用，但提供 API 给后续「分区画像」页。

### 2. dashboard 接入

`src/pages/dashboard/dashboard.vue`：

- 新 import：`getDistrict12WeekChangeRank` / `getDistrictRecentMomentumRank` 类型 `DistrictChangeEntry` / `DistrictMomentumEntry`。
- 4 个新 `computed`：`district12wChange` / `districtMomentumRank` / `districtDriftTotalWeeks` / `districtDriftTotalDistricts` / `districtDriftWithEnough`。
- 新卡片「📊 分区近 12 周均价变动」插在 v0.92.0 地铁卡后、v0.81.0 全国 NBS 卡前：
  - 顶部：涨跌计数 (`涨 X · 跌 Y`)
  - 主体：6 个 `stats70-cell`，城市 · 区 + `formatPct(change)` + `formatUnitPrice(latestPrice)`
  - 副卡：「近 4 周 vs 前 4 周动量 Top 3」，用 v0.91.0 / v0.92.0 同款 `drift-row` 行样式
  - 脚注：自解释 (总周数 / 总区数 / ≥12 周可观察区数)

### 3. 测试

`tests/districtDrift.test.ts`：5 个用例

- 派生涨跌比例（13 周天 vs 海，海 end < start 的真实数据，不靠 `0.9 * basePrices` 这种碎录式 mock）
- 周数不足 12 时回退到首尾比较
- 按 cityId 过滤
- momentum 排序 + null 沉底
- `getDistrictPriceSummary` 的窗口最高 / 最低与周数

## 兼容性

- 「已有」派生模块沿用，无需迁移
- 不破坏 v0.92.0 / v0.91.0 / v0.89.0 dashboard 卡片显示
- `districtDriftTotalWeeks` 用 `Date.parse` 估算周数，**仅用于显示**，不影响排序

## 已知边界

- `getDistrictTrends()` 返回**全部 15 区**——不分 cityId；dash top 6 全市场排序与单市场 Top 6 同源，需要单城市视图时传 `cityId` 参数即可。
- `weeksAvailable < 12` 的区依然参与排行（用首尾做基线），dashboard 脚注会显式声明样本完整度，避免「少 4 周却按 12 周排序」的误导。
- 单元测试覆盖排序、过滤、null 沉底、空快照；尚未覆盖 dashboard 模板（沿用 v0.91.0 / v0.92.0 已写好的样式类 `drift-up` / `drift-down`，肉眼回放即可）。
