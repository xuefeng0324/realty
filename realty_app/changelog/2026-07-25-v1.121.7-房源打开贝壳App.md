# v1.121.7 — 房源跳贝壳 + 离线 APK 补 zip4j（修 OTA 100% 闪退）

## 问题

1. 房源「查看参考页面」在 App 端只复制链接，浏览器反复登录。
2. 离线打包的整包 APK 检查更新：wgt **下载到 100% 后闪退**。根因是 `simpleDemo/build.gradle` 缺少官方依赖 `net.lingala.zip4j:zip4j:2.11.5`，`plus.runtime.install` 解压时 `NoClassDefFoundError`（云打包一般自带，离线包没有）。

## 改动

### JS / 页面

- `openExternal.ts`：贝壳 / 安居客 deep link；`listing-detail` 主按钮「打开贝壳找房」
- `appUpdate.ts`：wgt 落到 `_doc/update/`、安装前校验文件大小、安装失败给出 zip4j 提示
- `settings.vue`：安装成功后再弹重启；文案提示旧离线包需重装

### 整包 / 脚本 / 文档

- 本机离线 SDK `build.gradle` 已加 zip4j
- `scripts/build_apk_local.ps1`：自动注入 zip4j + 同步 versionCode
- `docs/BUILD_APK.md`：写明「缺 zip4j → 100% 闪退」

## 你要怎么做

**必须重装整包 APK**（zip4j 在原生层，OTA 补不了）：

`Desktop\RealtyApp-1.121.7-128.apk`（或 `unpackage/release/apk/` 同名）

装好后，以后的 OTA 才不会在安装阶段崩。
