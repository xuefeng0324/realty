# v1.123.84 · 全站渐变审计 + 数据可视化柱条 token 化

## 背景

v1.123.83 去除了 map-mode-tab 的违规渐变后，继续执行全站渐变审计。扫描到 45 处 `linear-gradient`/`radial-gradient`，按 v1.123.73 设计规则「UI 控件不使用渐变」分类：数据可视化渐变（图表柱条、进度条、热力图色阶）保留，UI 控件渐变（卡片、按钮、tab）去除。同时将数据可视化柱条中的硬编码蓝色 token 化。

## 修复内容

### 1. UI 卡片去渐变（dashboard.vue）

LPR KPI 卡片使用装饰性渐变，违反 UI 控件不使用渐变的规则，且硬编码色不随主题切换：

| 元素 | 原值 | 新值 |
|------|------|------|
| `.lpr-kpi-cell` 背景 | `linear-gradient(135deg, #fef3c7, #fde68a)` | `var(--color-warn-soft)` |
| `.lpr-kpi-cell` 边框 | `#fcd34d` | `color-mix(in srgb, var(--color-warning) 35%, transparent)` |
| `.lpr-kpi-cell--5y` 背景 | `linear-gradient(135deg, #fee2e2, #fecaca)` | `var(--color-danger-soft)` |
| `.lpr-kpi-label` 文字 | `#78350f` | `color-mix(in srgb, var(--color-warning) 75%, #000)` |

### 2. 数据可视化柱条 token 化

community `.chart-fill`/`.dim-fill`、listing-detail `.dim-fill` 的硬编码蓝渐变统一为既有模式（与 wq-fill/trend-bar-fill 一致）：

```css
/* 旧 */
background: linear-gradient(90deg, #3b82f6, #60a5fa);
background: linear-gradient(90deg, #2563eb, #60a5fa);
/* 新 */
background: linear-gradient(90deg, var(--color-focus) 0%, color-mix(in srgb, var(--color-focus) 80%, #000) 100%);
```

### 3. 删除冗余硬编码覆盖（App.vue）

浅色主题 `.score-high/mid/low` 的硬编码覆盖与 foundation.scss 中 token 值完全一致（`--color-warn-soft` 浅色即为 `#fef3c7`，`--color-on-warn-soft` 浅色即为 `#92400e`），删除 15 行冗余 CSS，消除 6 处硬编码色。

## 保留（数据可视化渐变）

- App.vue / listing-filter / school-detail hero 背景径向渐变：页面装饰背景，非 UI 控件，保留
- map-view mask-image 渐变：功能型遮罩，保留
- map-analysis 地图色阶渐变：数据可视化，保留
