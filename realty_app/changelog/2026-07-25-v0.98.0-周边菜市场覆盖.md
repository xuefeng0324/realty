# v0.98.0 周边菜市场/超市覆盖（仅数据层）

## 目标

把仓库根目录的 `realty_app/static/seed/poi_market.csv`（137 行 / 137 行覆盖多小区）从静态 CSV 升级成可派生指标 —— 不抓虫、不联网，零额外依赖。

## 数据

| 字段 | 来源 | 样例 |
|---|---|---|
| community_id | community 主表 ID | 1 |
| poi_category | 类目 | market |
| poi_rank | 1/2/3（每小区前 3 个最近） | 1 |
| poi_name | 真实 POI 名称 | 钱大妈(华润城润府店) |
| poi_type | 分类链 | 购物服务;综合市场;农副产品市场 |
| distance_m | 距离（米） | 69 |
| lat/lng | 经纬度 | 22.543475, 113.954175 |
| address | 详细地址 | 粤海街道铜鼓路大冲润府二期郡楼 105 铺 |

## 派生

`src/local/poiMarketRanking.ts` 新增 4 个函数：

1. `summarizePoiMarketByCommunity` —— 每个小区聚合（market 数 / 最近 / 最远距离 / 最近 market 名 / 经纬度中位）
2. `getPoiMarketNearestByCommunity(communityId)` —— 优先取 `rank=1`，无则回退取最近距离
3. `getPoiMarketDistanceLeaderboard(n)` —— 最近 / 最远 N 个小区榜
4. `getPoiMarketByCategoryRanking` —— 按 poiType 类别（综合市场 / 蔬菜市场 / 购物相关场所）的覆盖分布 + 平均距离

## 接入链路

1. `src/local/types.ts` 新增 `LocalPoiMarket` 接口与 `DataSnapshot.poiMarkets: LocalPoiMarket[]` 字段
2. `src/local/importer.ts` 新增 `parsePoiMarket` + `inputs.poiMarketCSV`
3. `src/local/snapshotLoader.ts` 把 `["poiMarketCSV", "poi_market.csv"]` 加入 `OPTIONAL_FILES`
4. `src/local/seedSnapshot.ts` 把 `poi_market.csv?raw` 注入 `inputs`
5. `src/local/store.ts` 新增 `getPoiMarkets()` 与 `getPoiMarketsByCommunity(communityId)`

## 测试

`tests/poiMarketRanking.test.ts` —— 5 用例：

- `getPoiMarketNearestByCommunity` 优先 rank=1 / 回退 / 未知 community

- dashboard 已累计 ≥10 张卡（v0.87 ~ v0.97），继续叠加会让首屏高度过 5 屏，影响 320px 小屏体验
- 这两个 page 之前没有"周边设施"分类卡，加载路径完全不同（detail 而非列表）
- 数据先就位、UI 分离决策更稳妥
