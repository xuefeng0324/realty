# 2026-07-28 v1.121.140 OTA bump（承接概览收敛）

**versionName**：1.121.140 · **versionCode**：261

## 为什么发这一版

上一轮业务提交 `refactor(dashboard): remove scroll progress and compact overview`
只改了 `dashboard.vue` / 测试 / 文档，**没有**跑 `bump-version.mjs`。

结果：

- 仓库代码已是「无进度条 + 概览精简」
- 但 OTA 清单仍是 CI 为 **1.121.139 / versionCode 260** 打的包
- App 端比较 `versionCode`：本机已是 260 → 认为没有更新 → 热更新不了

按 [docs/VERSIONING.md](../docs/VERSIONING.md)：出 OTA / 改业务页面 **必须** bump；`versionCode` 一律 +1。
