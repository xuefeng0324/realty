# v1.123.28 dashboard scoped 样式死类清理

## 背景

v1.123.22 ~ v1.123.27 连续删除了大量被壳层 CSS 永久隐藏的卡片 DOM，但卡片对应的 scoped 样式仍全部留在 dashboard.vue 的 `<style>` 段中。本轮用「模板全文（截至 `<style`）逐类引用比对」把样式段中零引用的类全部扫出来，一次性清理。

扫描范围：dashboard.vue 的 scoped 样式段（含 media query）。判定：类名（`.foo`）在模板文本中无任何出现（包括 `:class` 表达式内的字符串）即视为死类，再逐个人工复核动态拼接用例。
