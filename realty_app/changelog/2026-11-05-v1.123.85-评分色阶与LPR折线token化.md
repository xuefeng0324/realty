# v1.123.85 · 评分色阶 + LPR 折线 + slider 激活色 token 化

## 背景

v1.123.84 完成全站渐变审计后，继续扫描剩余硬编码色（不限于 CSS style 块，还包括 JS 函数返回值、SVG 属性、uni-app 组件 prop）。发现 3 类可迁移的硬编码色。

## 修复内容

### 1. dashboard 学区维度评分色阶（schoolDimsColor）

`schoolDimsColor(score)` 按分数返回四档颜色，用于学区维度评分条背景。原硬编码色不随主题切换：

| 分数段 | 原值 | 新值 |
|--------|------|------|
| >= 70 | `#34d399`（emerald-400） | `var(--color-success)` |
| >= 50 | `#60a5fa`（blue-400） | `var(--color-focus)` |
| >= 30 | `#fbbf24`（amber-400） | `var(--color-warning)` |
| < 30 | `#f87171`（red-400） | `var(--color-danger)` |

该函数返回值直接用于 `:style="{ background: schoolDimsColor(score) }"`，CSS 变量在 inline style 中正常工作。

### 2. dashboard LPR 折线（SVG）

LPR 5Y 历史走势 sparkline 的 SVG `stroke` 和 `fill` 硬编码 `#ef4444`，改为 `var(--color-trend-up)`，折线色随深浅主题切换（深色 `#f87171` / 浅色 `#dc2626`）。

### 3. listing-filter 价格 slider 激活色

4 处 `<slider>` 的 `activeColor="#22c55e"`（green-500）改为 `activeColor="var(--color-primary)"`。同组件的 `backgroundColor="var(--color-soft-strong)"` 已使用 CSS 变量，证明 prop 支持 CSS 变量。slider 激活色由固定 green-500 改为随主题（浅色 `#16a34a` / 深色 `#22c55e`）。

## 保留
