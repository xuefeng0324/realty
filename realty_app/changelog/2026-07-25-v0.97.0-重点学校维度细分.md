# v0.97.0 — 重点学校维度细分（school.vue mini 卡）

日期：2026-07-25

## 目标

`static/seed/school_dimensions.csv` 50 行（每行一个"重点学校" × 5 维度：综合排名分 / 集团校实力 / 区均衡度 / trendDelta / compositeScore）+ 学校名 / 城市 / 区 / 类型 — 这些数据过去只有 `getSchoolDimensions()` 接但**没有 UI 视图**。

v0.97.0 派生 4 个函数 → 挂到 school.vue 的"教育"主题上：

- "**六边形战士**"：综合分≥80 + 集团实力≥70 + 区均衡度≥70 同时满足的学校
- "**三维度 Top 1**"：当前城市的综合排名 / 集团实力 / 区均衡度 最强学校
- "**各市综合最强**"：按 compositeScore 取每市最强学校
- "**每市统计摘要**"：学校数 / 平均综合 / 平均趋势变化

完全派生，零抓虫。

## 关键改动

### 1. 新增 `src/local/schoolDimensionRanking.ts`

四个公开函数 + 三个类型导出：

- `summarizeSchoolDimensionsByCity()` → `CityDimensionSummary[]`
  - 按 cityId 聚合
  - 输出：`{ cityId, cityName, schoolCount, avgComposite, avgTrendDelta }`
  - 排序：avgComposite 降序

- `getSchoolDimensionByDimensionTopN(dimension, cityId?, n=5)` → `SchoolDimensionEntry[]`
  - 维度字段：`levelScore` / `groupStrength` / `districtBalance`
  - 默认按分数降序
  - 支持按 cityId 过滤

- `getSchoolDimensionPolymath(cityId?, cfg)` → `SchoolDimensionEntry[]`
  - 默认阈值 `{ levelScoreMin: 80, groupStrengthMin: 70, districtBalanceMin: 70 }`
  - 三阈值都达标才返回
  - 按 compositeScore 降序

- `getCityByCompositeRank()` → `CityTopComposite[]`
  - 每市 compositeScore 最高的学校
  - 排序：top 学校的 score 降序

### 2. school.vue 接入

`src/pages/school/school.vue`：

- 新 import + 4 个 computed：`dimCitySummary` / `dimPolymathList` / `dimTopLevel` / `dimTopGroup` / `dimTopBalance` / `cityByComposite`
- 新卡「🏫 重点学校维度细分」**插在 v0.87.0 教育事业概览之后**（紧邻主题）：
  - 顶部：重点校总数 + 覆盖城市数
  - 主体：6 边形学校 Top 4（按 compositeScore 降序）+ 城市 · 区 · 类型 副标

  - 脚注：自解释 (50 行重点校子集)

`data-school-dimensions` 属性挂上，方便 e2e 测试与 READMEs 串联。

## 设计取舍

| 维度 | 决策 | 理由 |
|------|------|------|
| 进 school.vue 而非 dashboard | dashboard 已 10 张 | school.vue 是教育主题页，派生方向"重点学校维度"和"教育概览"无缝衔接 |
| 阈值 80/70/70 默认 | 经验值 | 综合分 ≥ 80 = 重点校门槛，集团 / 区均衡度 ≥ 70 = "高于平均但非极严" |
| `dimPolymathList.slice(0, 4)` 限制 4 条 | 与 v0.92/93/94/95/96 保持一致 | 卡内显示 Top 4，留更多上下文给趋势 / 各市综合 |
| `getCityByCompositeRank` 不按 cityId 过滤 | 与 polymath 错开主题 | 这是"全景"列表，不绑当前城市 |
| `compositeScore > best.compositeScore` 严格 > | 而非 ≥ | 同分时取首条更稳定 |
| `drift-row` 复用 | 与 v0.93/94 一致 | 节省样式表，4 个 continuous 派生共享 row |

## 兼容性

- `school_dimensions.csv` 数据没改动，store 接口 `getSchoolDimensions()` 已存在，本派生模块**纯增量**
- 不破坏 school.vue 既有"教育概览 + 搜索"两块主流程
- `v-if="dimCitySummary.length > 0"` 包裹整张卡，snapshot 缺 schoolDimensions 时整张卡消失

## 已知边界

- "六边形" 阈值 80/70/70 沿用 v0.47.0 重点校经验值，未量化校准；用户用一段时间后可能觉得"过宽 / 过严"。
- school_dimensions.csv 50 行覆盖 1-2 个城市（看 `crawl_school_dimensions.py` 实际跑覆盖度），当覆盖 1 个城市时 `dimTopLevel/Group/Balance` 三 grid 都只显示 1 个学校。
- 不接 `school_indicators.csv`（v0.94.0 已派生），本次只接 `school_dimensions.csv` — 两个数据源交叉对齐留作未来增强。
- `dimCitySummary` 是无 cityId 过滤的全市场摘要，卡顶部显示 "50 所重点校"。如做"按当前城市切片"，需要再独立导出按城市摘要。
