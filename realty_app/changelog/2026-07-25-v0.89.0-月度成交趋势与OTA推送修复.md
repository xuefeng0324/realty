# v0.89.0 —— 月度成交趋势派生 + 本地一键 APK + CI 推送修复

> 2026-07-25 · 关系自检：manifest versionName 0.89.0 / versionCode 90 /
> config.APP_VERSION 0.89.0 / README 已新增此条。

## 改了什么

1. **月度成交趋势（无需新增抓取）**
   - `src/local/dailyWangqian.ts` 新增 `getMonthlyTrendFromDaily(city, category, months=12)`
     与 `summarizeMonthlyTrend()`：直接读 `daily_wangqian.csv` 的
     `granularity=city` 行，按 `yyyy-mm` 聚合，返回 `[month, days, units, area_sqm, prevUnits, prevArea]`。
   - `src/pages/wangqian/wangqian.vue` 新增「月度成交趋势（住宅 · 套数）」
     卡：两行（新房/二手），各为 sqrt 拉伸 sparkline + 环比 + 最新月数值。
   - `tests/monthlyTrend.test.ts` 5 个用例覆盖：聚合正确 / 环比正确 /
     新房二手独立 / 排除分区粒度行 / 空数据降级。

2. **本地一键 APK 出包 (`scripts/build_apk.ps1`)**
   - 自动 `type-check` + `npm test` + `npm run build:app`；
   - 校验 `dist/build/app/` 体积/文件数；
   - 给出一段 HBuilderX 5–10 分钟手动出 APK 的最少步骤提示。
   - 完全自动的云端打包需要 DCloud 账号登录，脚本不替你点（防误登）。
   - 文档 `docs/BUILD_APK.md` 重写：
     * 加 §0「平时 CI 自动做了什么」：让读者一秒明白 OTA 是 push-即生效；
     * 加 `apk-cloud-build.yml.example` 引用，提示完整自动化路径仍需 GitHub Secrets。

3. **CI 推送失败修复（v0.88.0 引入但没撞过的回归路径）**
   - `git checkout -B $BRANCH $GITHUB_SHA`：修正 `actions/checkout` 默认
     detached HEAD 导致 `git push` 在新会话里无上游；
   - `git push https://x-access-token:${GITHUB_TOKEN}@github.com/... HEAD:$BRANCH`：
     显式 token URL，绕开可能的 credential helper 不可用；
   - 升级 `actions/setup-node@v4` → `@v5`（三个 workflow：build-app-wgt /
     realty-app-tests / realty-app-e2e），消除 Node.js 20 deprecation 警告。

4. **版本对齐**
   - `src/manifest.json` versionName `0.88.0`/`89` → `0.89.0`/`90`
   - `src/config.ts` APP_VERSION 同步 `0.89.0`
   - CI 自动出包会再覆盖 `static/update/` 内的 manifest（带真实 sha256）

## 不改什么

- 不增加新抓虫 / 新外部源 / 新依赖（沿用原有 npm scripts）；
- 不动 OTA 协议与 `app-update.json` schema（保持 CDN 兼容）；
- 不动 wangqian 顶部已存在的 90 日趋势 + 月度公示卡片（避免视觉拥挤）。
