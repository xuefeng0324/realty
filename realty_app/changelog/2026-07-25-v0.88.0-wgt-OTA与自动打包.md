# v0.88.0：wgt OTA 升级 + GitHub Actions 自动出包

## 目标

每次把代码 push 到 `main`：

1. **自动出 wgt**（uni-app 应用资源包，本质 zip）
2. **自动发布 OTA 清单**（`static/update/app-update.json`），App 内「检查更新」即可下载安装
3. **整包 APK** 在 `docs/BUILD_APK.md` 给出三种路径，按需启用

不再需要每次手动打开 HBuilderX 用 adb 安装。

## 变更

- 新增 `.github/workflows/build-app-wgt.yml`：
  - push 触发 → npm ci → type-check → npm test → `npm run build:app` → 计算 sha256 → 生成 `app-update.json` → 自动 commit & push 回 main → jsDelivr CDN 即时生效
  - `app-update.json` 含 versionName / versionCode / publishedAt / notes / wgt.url / wgt.sha256 / ios.available
  - 失败步骤会把 npm/test 输出原样贴回 Actions 日志，便于排查
- 新增 `src/utils/appUpdate.ts`（条件编译 `#ifdef APP-PLUS`）：
  - `checkAppUpdate()`：fetch 清单 → 比 versionCode → 返回 `available` / `up-to-date` / `skipped` / `unsupported`
  - `downloadAndInstallWgt(url, onProgress)`：用 `plus.downloader` 拉 → `plus.runtime.install(force=true)` → 提示用户重启 App
  - `skipVersion()`：用户点「跳过该版本」时写本地 storage
  - `getLocalVersion()`：读 `plus.runtime.getProperty` 拿本地 versionCode
- `src/pages/settings/settings.vue` 加「应用升级」卡（条件编译 APP-PLUS）：
  - 当前版本号 + 检查更新 + 下载并安装 + 跳过
  - iOS 用户按钮隐藏（OTA 在 iOS 上需要 App Store 整包）
  - 「Releases」链接跳 GitHub Releases 页
- `src/config.ts` 新增 OTA 常量：
  - `UPDATE_BASE_URL`（jsDelivr gh 路径）
  - `APP_UPDATE_STORAGE_KEY` / `APP_GITHUB_REPO`
- `src/manifest.json` 升 `versionName: 0.87.0` / `versionCode: 89`
- 新增 `realty_app/static/update/app-update.json`（首版占位，CI 会覆盖）
- 新增 `realty_app/docs/BUILD_APK.md`：整包 APK 三种路径说明
- README 版本表新增 v0.88.0 行

## 数据流

```
push main
   ↓
GitHub Actions → build-app-wgt.yml
   ├─ build:app → dist/build/app/{manifest.json, app-service.js, ...}
   ├─ zip → static/update/<versionCode>/app.wgt
   ├─ sha256 + versionCode + notes
   └─ 写 static/update/app-update.json + commit + push
                                ↓
jsDelivr CDN
   ├─ app-update.json
   └─ <versionCode>/app.wgt
                                ↓
App 设置页「检查更新」
   ├─ fetch(app-update.json)
   ├─ 比 versionCode
   └─ 「下载并安装」 → plus.runtime.install → 重启生效
```

## iOS 限制说明

uni-app 的 wgt OTA 升级在 iOS 上仅在以下场景可用：

- 通过 **企业证书** 签名的内部 App
- 通过 **TestFlight** 分发的内测版本
- 自签 IPA（开发者证书）

已上架 **App Store** 的应用不能用 wgt OTA（违反审核规则），必须走整包审核。
本仓库当前未上架任何平台，所以 iOS 用户**只能**装 HBuilderX 出的本地整包或等 APK 流程。
