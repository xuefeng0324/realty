## 目标

复用既有 v0.39.0 + v0.40.0 完整链路（`feature_premium.csv` + `tag_combination.csv` 已入 snapshot），新增两套高阶派生，让"什么最值钱 / 什么最常搭"这两类分析在数据层就绪。

## 数据

### feature_premium.csv（v0.39，51 行）

| city_id, city_name | 城市 |

## 派生

### `src/local/featurePremiumRanking.ts`（5 函数）

1. `summarizeFeaturePremiumByCity` —— 每城聚合（top bucket / bottom bucket / 平均溢价）
2. `getFeaturePremiumByCityDimension(cityId, dim, opts)` —— 单 city 单 dimension 全部 bucket（默认按 premium 倒序，可切 bucket 字典序）
3. `getFeaturePremiumTopByDimension(cityId, dim)` —— 单 city 单 dimension 溢价最高 bucket
4. `getFeaturePremiumCrossCityLeaderboard(dim)` —— 跨城对比某 dimension 中"哪城哪桶"溢价最深
5. `getFeaturePremiumByDimensionCoverage(n)` —— 全 (city, dim, bucket) 按 |premium| 倒序 Top N

### `src/local/tagCombinationRanking.ts`（5 函数）

1. `summarizeTagCombinationByCity` —— 每城聚合（组合数 / 总 listing / 平均 share + count）
2. `getTagCombinationPopularByCity(cityId, n)` —— 单城按 count 降序 Top N
3. `getTagCombinationPremiumByCity(cityId, n)` —— 单城按 avgUnitPrice 降序 Top N（**null 排到末尾**）
4. `getTagCombinationCrossCityMostCommon(n)` —— 跨城出现 ≥ 2 城的"标签 pair"，按累计 count 倒序
5. `getTagCombinationCrossCityByTag(baseTag, n)` —— 某 tag 跨城最常与哪些 tag 组合

## 中文排序要点

- `localeCompare(b)` 默认按 unicode code point，**不是中文拼音**
- `localeCompare(b, "zh-Hans-CN")` 仍是 code point
- 因此中文排序 = unicode 顺序 = `豪 > 精 > 毛`（豪 0x8c6a > 精 0x7cbe > 毛 0x6bdb）
- 测试断言改用"按字符串自身字典序排后等于派生输出"而非硬编码固定顺序，避免被实现细节锁死
