# v1.123.33 E2E 非 suite 脚本收口：3 修 7 删

## 背景

v1.123.32 已把 12 个 stale orphan 脚本清理完，但 `tests/e2e/` 仍剩 23 个不在任何 suite 的脚本——其中 9 个实跑 FAIL。本轮全部取证后按「可修 / 断言过期」二分处置，不再凭文件名猜。

## 改动

**A. 实跑取证（23 个非 suite）**

- PASS 14 个（admin 修前 FAIL / hospital 修前 FAIL / metro 修前 FAIL / content_scaling / dashboard_compact / dashboard_feed_seam / enrich / full_interactions / full_pages / listings / map_controls / metro_overlay / poi / responsive_layout / school_detail / theme_buttons）
- FAIL 9 个 → 二分：
  - 环境类（3 个）：`smoke_admin` / `smoke_hospital` / `smoke_metro` 的 CSV 断言走 HTTP `page.request.get(BASE + "/static/seed/*.csv")`，但 dev server 下 static/seed 根本不映射为 HTTP 路径，永远 404
  - 断言过期类（6 个）：`smoke_school_dims`（5186 死端口 + `.form-row` 类 v1.123.28 已删）/ `smoke_weather`（text=实时天气 超时 → 天气卡已删）/ `smoke_district_trend`（`.trend-row` 超时）/ `smoke_district_wangqian_rank`（`.picker-value` 超时）/ `smoke_map_find`（底栏挂牌断言过期）/ `smoke_price_heatmap`（图例「城市均价」过期）/ `smoke_poi_overlay`（图例「聚合」过期）

**B. 修 3 个：CSV 断言从 HTTP 改 fs 本地读取**

`smoke_admin` / `smoke_hospital` / `smoke_metro` 的 CSV 校验目标是「数据文件在 repo 里存在且内容正确」，不是「dev server HTTP 可访问」——HTTP 断言在 dev 环境下永远是假断言。改为 `readFileSync(resolve(process.cwd(), "static", "seed", ...))` + `existsSync`，页面渲染部分的断言一个没碰（原来就过）。

**C. 删 7 个：断言过期 + 无法修复**

`smoke_school_dims` / `smoke_weather` / `smoke_district_trend` / `smoke_district_wangqian_rank` / `smoke_map_find` / `smoke_price_heatmap` / `smoke_poi_overlay`。根因：要么端口/类已死、要么断言文本与当前实现不一致且没有修复价值（修了也是让死断言看起来通过，不是真回归）。

**D. 防回归门禁（`tests/buildIntegrity.test.ts`）**

- 7 个已删脚本路径必须不存在
- 3 个 CSV 脚本必须用 `readFileSync/existsSync`，且禁再出现 `/static/seed/*.csv` 的 HTTP `.get` + `.status()===200`
