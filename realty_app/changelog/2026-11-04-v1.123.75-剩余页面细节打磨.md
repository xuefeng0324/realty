# v1.123.75 · 剩余页面细节打磨（地图找房 / 供需 / 设置 / 汇市）

## 背景

延续上一轮「散点修复 + 首轮细节清理」，本轮集中检查尚未覆盖的 6 个页面（我的 / 学校 / 供需 / 房源详情 / 地图找房 / 宏观汇市），修复选择态、表格结构、单位与文案问题，并再次通过完整验证链。

## 真实问题

1. **地图找房城市选择态失效**：城市按钮同时带 `.btn` 与 `.city-option`，页面又用 `.btn { background: ... !important }` 覆盖，导致深圳 / 广州 / 珠海三个按钮全部显示为绿色选中态，无法判断当前城市。移除整页 `.btn` 强制覆盖，城市按钮改用独立的 `city-option` 样式（含 `--color-primary` 选中态、`--color-text` 未选中态）。
2. **图层与 POI 仍有 emoji**：地图图层 chip（🏠/🔴/💰/🏫/🚇）和 POI 标记标题仍带 emoji，违反设计章程；图标字段整体移除，POI 标记改用「类别 · 名称」纯文字。
3. **供需页分区表无表头**：广州库存表每一行都重复「可售 / 未售 / 签约」标签，11 行重复且列宽跳动；新增表头行，数值列右对齐，行内只保留数字。商业/办公分区表同样补表头。
4. **土地成交行日期换行**：`黄埔区 · 2026-10-14` 在窄列内被拆成两行；行政区与日期改为上下两行，日期用 micro 字号。
5. **汇市金额单位混乱**：`亿$`、`万亿$`、`万亿¥` 与脚注「亿美元」不一致，且页面同时显示「34,001 亿美元 (≈ 3 万亿美元)」重复信息。统一为「亿美元 / 万亿美元 / 万亿元」，合计只保留万亿美元；脚注补「单位：」。
6. **房源详情空图文案重复**：标题「暂无实景图」下方描述又写「暂无实景图；……」；描述改为仅在可打开源站时显示「点此处或底栏打开源站查看图集。」
7. **设置页技术词**：`sha:` → `版本`；「政府网签（深广）」→「深圳 / 广州」；「经 CDN 同步到本机」→「自动同步到本机」；更新卡「GitHub Actions build-app-wgt → jsDelivr CDN」→「每日自动构建并分发」。挂牌可信度分隔符由 `/` 改为 `·`，并去掉重复的「真实挂牌最新」。
8. **地图分析边缘标签裁切**：行政区标签 x 仅做了冲突避让，最西侧区县仍可能贴边；补 x 轴 7%~93% clamp。
