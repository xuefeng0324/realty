# v0.60.0：首页按需渲染与广州新房库存

## 变更

- 六张首页概览长卡从 CSS 裁切改为 Vue 条件渲染：折叠时仅保留关键摘要，展开后再创建榜单、图表和交互控件。
- 广州城市新增住建局官方商品住宅库存卡，展示全市可售、未售和当日签约，并允许按按钮展开 11 区明细。
- 新增标准库抓取脚本，并接入每日网签 CI，持续更新 `gz_new_house_inventory.csv`。
- 库存 CSV 按日期和行政区去重追加，加载器只汇总最新日期，既避免历史重复累计，也为后续趋势分析保留序列。
- 补充单元测试和 E2E 按钮验证，覆盖折叠 DOM、全部展开/收起及广州库存明细展开/收起。

## 数据口径

- 数据来自广州市住建局商品房销售统计公开接口，无需登录。
- 可售与未售是两个并列官方口径，不互相替代。
- 不使用单日签约量推算去化周期，避免把日波动包装成稳定市场指标。
