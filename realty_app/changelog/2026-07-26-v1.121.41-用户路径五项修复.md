# v1.121.41 — 用户路径五项修复（周切换 / 本市隔离 / App 唤起 / 区筛 / 分页）

**日期**：2026-07-26  
**versionName**：1.121.41 · **versionCode**：162

## 问题与修复

### 1. 总览「切换周」看起来没变化

- **根因**：周切换只刷新小区周榜/区对比，但页面堆满不随周变的派生卡；`data-tab="all"` 的 CSS 也错误地把「全 tab」卡藏掉。
- **修复**：修正 tab CSS（`:not([data-tab*="all"])`）；增加「本周速览」条（上榜小区数 / 有数据区 / Top1），切周后 toast + 滚到该条；周榜标题带 `weekEnd`。

### 2. 选了深圳仍混广州数据

- **根因**：大量「跨城对照」默认可视，用户以为选城失效。
- **修复**：默认「仅本市」；顶栏可切「含跨城」；跨城 computed 在本市模式下返回空数组。房源筛选页去掉三市横评混显。

### 3. 房源「参考页」总进浏览器

- **根因**：deep link 失败静默回落 https，用户无选择。
- **修复**：App 端 `ActionSheet`：打开贝壳/安居客 / 浏览器 / 复制；多候选 scheme + Android Intent + `isApplicationExist`；manifest 增加 package queries / iOS scheme whitelist。

### 4–5. 筛选不能选区、只显示约 20 条

- **修复**：行政区选择器；`filterListings` 支持 `districtName`；分页 30/页 +「加载更多」；展示「共 N 套 · 已显示 M · 本市样本总量」。
