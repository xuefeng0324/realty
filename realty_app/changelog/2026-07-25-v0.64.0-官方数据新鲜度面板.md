# v0.64.0 官方数据新鲜度面板

## 变更内容

- 设置页新增“官方数据新鲜度”面板，避免继续拉长首页。
- 集中展示国家统计局 70 城指数、深广政府网签、广州新房库存、住房公积金利率四类官方数据。
- 每项显示最新数据日期、官方来源域名和状态；周期数据按正常发布频率判断“正常 / 偏旧 / 缺失”，政策利率标记为“现行政策”。
- 网签远程刷新或恢复包内数据后，状态面板会同步重新计算。
- 扩展设置页 E2E，验证四个来源和四个状态标记均正常渲染。

## 设计取舍

数据健康信息放在设置页而非首页，保留可核验性同时不增加首屏和长页面负担。新鲜度只做提示，不改写、推断或填补原始数据，防止把“更新频率”误当成“数据内容真实性”。
