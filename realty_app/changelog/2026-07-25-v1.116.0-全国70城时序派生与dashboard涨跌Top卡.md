# v1.116.0 · 全国 70 城时序派生与 dashboard 涨跌 Top 卡

**日期**：2026-07-25
**类型**：数据派生 + UI 接入（**首次落地**，结束连续 16 个版本 "派生-不入界面"）

## 背景

v0.98.0 至 v1.115.0 连续 16 个版本都只做派生、不接 UI。本版本选择最有产品价值的派生
（**全国 70 城价格指数的时序信号**）落地到 dashboard，让用户直观看到：

- 自己城市在全国 70 城里位置（**Top % 排位**）
- 同期全国涨/跌城市分布
- 新建 同比 涨 / 跌 Top 5 城市

## 派生模块

`realty_app/src/local/stats70TrendAnalysis.ts` 新增 9 个函数：

| 函数 | 作用 |
|------|------|
| `getStats70MonthOptions` | 全部可选月份（数值化排序，避免字典序把 11/12 排在 2/3 前） |
| `getStats70LatestMonth` | 最新月份字符串 |
| `getStats70LatestByCity` | 单 city 最新月 4 指数（newYoY/newMoM/secondYoY/secondMoM） |
| `getStats70TopByTypeByMonth` | 某月某 fixed_base × new/second 跨城 Top N（涨/跌） |
| `getStats70CurrentCityNationalRank` | 当前 city 在全国排位（多少城里 top X%） |
| `getStats70CityOver12MonthChange` | 单 city 近 12 月（同比）的 4 个指数变化轨迹 |
| `getStats70CrossCityByMonthSpread` | 某月 4 指数的"最值差"（全国最分散程度） |
| `getStats70CityTrendDirection` | 单 city 近 3 月趋势方向（涨/跌/平稳） |
| `getStats70CrossCityByCityCount` | 4 指数下"上涨城市数" / "下跌城市数" |

### 关键设计

**字符串日期数值化**：crawler 输出 `YYYY/MM/DD`（零填充）—— `compareMonthStr` 把 `"2025/12/1"`
拆成 `2025*10000 + 12*100 + 1`，避免 `String.localeCompare` 把 `2025/12/1 < 2025/2/1` 这种字典序陷阱。

## UI 接入（dashboard）

`realty_app/src/pages/dashboard/dashboard.vue` 在"全国 70 城价格指数"卡下方新增
**"全国 70 城 · 涨跌 Top"** 卡片，含：

- **4 指数涨/跌城市数**（同比/环比 × 新建/二手 4 维）
- **当前城市排位**（"深圳 · 全国 Top 12% · 同比 105.8"）
- **近 3 月趋势方向**（涨/跌/平稳，含平均 pp 变化）
- **新建同比涨 Top 5**（城市 + 指数）
- **新建同比跌 Top 5**

样式类：`trend-summary` / `trend-cell` / `rank-row` / `trend-row` / `top-section` / `trend-up`(红) / `trend-down`(绿)。

中国习惯：指数 > 100 = 涨（红），< 100 = 跌（绿）。

### 测试调试记录

- **空 snapshot 失败 1**：派生函数 sort 时用 `compareMonthStr(a, b)` 但 a 是 LocalStats70Row
  对象而非字符串 —— 改为 `compareMonthStr(a.date, b.date)`。
- **空 snapshot 失败 2**：`getStats70CrossCityByCityCount` 在空数据时仍 push 4 个 0-count
  entry —— 加 `if (subset.length === 0) continue;`。
- **trace 排序错**：测试日期用 `"2024/${i+1}/1"`（i+1=15 时 `2024/15/1` 无效月份）——
  改为跨年 15 个月（2024/01 .. 2025/03）验证近 12 月窗口。
