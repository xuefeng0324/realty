# v1.123.34 UI foundation 补齐变体类 + dashboard 样式治理

## 背景

dashboard.vue 一直靠 `<style lang="scss">`（无 scoped）里的 `.card { border-radius: 0; box-shadow: none; }` 全局覆盖来实现"扁平分隔线"风格。这有两个问题：
1. **全局污染风险**——虽然 uni-app H5 每个页面的 CSS 只在该页 active 时注入，但无 scoped 的样式在全局注册，将来若有页面多卡共存（如 Tab 切页缓存），全局覆盖会打架。
2. **模板里 254 处内联 style**——其中 dashboard 独占大量 `style="margin-bottom: 0"`（`.card-title` 不想留 space-3）和 `style="font-size: 22rpx"`（`.muted` 想更紧凑），这些值本来就在 foundation.scss 的 token 体系里（`--space-1/3`、`--font-caption`），只是没有对应的语义化变体类。

本轮以"零视觉回归"为前提做纯结构性优化。

## 改动

**A. foundation.scss 补 3 个语义化变体类**

| 类 | 用途 | 值来源 |
|---|---|---|
| `.card-flat` | 扁平卡片（dashboard 壳层） | 复用 `.card` 的 `--space-4` padding + `--color-surface` background；用 `border-bottom: 1rpx solid var(--color-border)` 替代全边框 |
| `.card-title--flush` | 紧贴上边距的 card-title | `margin-bottom: 0`（覆盖 `.card-title` 默认的 `var(--space-3)`） |
| `.muted-caption` | 小号说明文本 | `font-size: var(--font-caption)`（22rpx）|

**B. dashboard.vue 改造**

- `<style lang="scss">` → `<style lang="scss" scoped>`，消除全局污染
- 删除 CSS 里的 `.card { margin-bottom: 0; border-radius: 0; box-shadow: none; ... }` 全局覆盖
- 模板机械替换（node 脚本）：
  - 18 个 `class="card ..."` → `class="card-flat ..."`（保留 `card-title` / `card-active` / `card-hide-btn` 等修饰类）
  - 10 个 `class="card-title" style="margin-bottom: 0"` → `class="card-title card-title--flush"`
  - 53 个 `class="muted" style="font-size: 22rpx"` → `class="muted muted-caption"`

**C. 验证——视觉零回归**

dashboard 渲染结果与之前完全一致：
- `.card-flat` 计算样式：`border-radius: 0px`、`box-shadow: none`、`border-bottom: 1px solid rgba(148, 163, 184, 0.16)`、`background: rgb(17, 24, 39)`
- `.card-title--flush`：`margin-bottom: 0px`
- `.muted-caption`：`font-size: 19.136px`（22rpx 正确换算）
- layout-diff：签名 382（+0 / -0）、元素 2543、锚点组 42/42
