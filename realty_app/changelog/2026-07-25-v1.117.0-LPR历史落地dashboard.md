## UI 接入（dashboard）

`realty_app/src/pages/dashboard/dashboard.vue` 在 v1.116 "全国 70 城涨跌 Top" 卡之后
新增 **"🏦 LPR 与房贷利率"** 卡，含：

- **4 指数当期值**：1 年期 LPR / 5 年期以上 LPR / 首套房贷 / 二套房贷（百分比 %）
- **12 月同比 bp 变化**：相对去年同月升降（bp = basis points = 0.01%）
- **累计降息**（自首次降息起，5y LPR + 首套房贷 bp 总降幅）
- **最长"按兵不动"月数**：单次连续不变最长期（信号 = 利率周期稳定期）
- **5y LPR 年度末值**（按年回看，5-10 年历史趋势）

### 配色约定

中国习惯 **降息=绿色 / 加息=红色**（与 70 城 "涨红跌绿" 相反，因为降息对购房者是利好）。
派生函数 `getLprDelta` 用 `Math.round((a.lpr1y - b.lpr1y) * 100)` —— 正数 = 早期高 / 近期低 = 降息。

## 12 月变动计算

`lprDelta12m` computed：

```ts
const parts = latest.month.split("-");  // "2025-06" → ["2025", "06"]
const y = parseInt(parts[0], 10);       // 2025
const m = parseInt(parts[1], 10);       // 6
const fromMonthStr = `${y - 1}-${m.toString().padStart(2, "0")}`;  // "2024-06"
return getLprDelta(fromMonthStr, latest.month);  // 2024-06 → 2025-06
```

选择 YoY（同比）而非 "近 12 月 MoM 累计"，理由：LPR 月度调整不连续（可能几个月才调一次），
YoY 跨年比较更能反映"周期内累计降息幅度"。
