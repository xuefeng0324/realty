# v0.68.0 API契约与日期边界测试

## 变更

- 新增8个API薄封装测试，验证路径、GET/POST参数、默认值和ID路径拼接。
- 新增8个格式化工具测试，覆盖万元/亿元、单价、面积、评分颜色、覆盖率和中文维度名。
- 验证自然日计算不受当前时刻影响，并支持未来日期返回负数。
- 修复`2026-02-30`、`2026-13-01`等不存在日期被JavaScript自动滚动后误判为有效日期的问题。

## 风险控制

API测试使用HTTP客户端mock，不发真实网络请求；测试重点是页面调用层是否把参数传到正确接口。真实网络错误和HTTP解析继续由`http.test.ts`覆盖。
