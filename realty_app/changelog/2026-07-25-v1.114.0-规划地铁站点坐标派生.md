## 背景

`LocalMetroLineGeo` 自 v0.15 起就接入了全链路（types / importer / snapshotLoader /
store），但 0 个派生函数消费它。每行起终点带 lat/lng + confidence 等级，是**地理坐标派生**
的天然输入。

**与 v1.110 metroPlanningRanking 的关键差异**：v1.110 派生于 `metro_planning`（含
lengthKm / stationCount / openYear），v1.114 派生于 `metro_planning_geo`（含
lat/lng + confidence）—— **同一规划线路的"语义视图"和"地理视图"互补**。

## 11 个派生函数

| 函数 | 作用 | 价值场景 |
|------|------|----------|
| `haversineKm(lat1, lng1, lat2, lng2)` | Haversine 直线距离 km（基础工具） | "任意两点直线距离" |
| `straightLineMeters(g)` | 单 line 起终点直距 m（端点齐全才返回） | "深圳 18 号线起终点直线距离" |
| `summarizeMetroPlanningGeoByCity` | city 聚合：线路数 + 起/终 5 confidence 分布 + 平均/最大直距 | "深圳 13 条起 high/8 条 manual" |
| `summarizeMetroPlanningGeoByConfidence` | 5 confidence 维度（全国跨城）：count + city 数 + top5 线路名 | "high 21 个 vs manual 8 个" |
| `getMetroPlanningGeoByConfidence(level)` | 某 confidence 全部（起或终至少一端为该值） | "所有 manual 兜底的线路" |
| `getMetroPlanningGeoByCityStraightLineTop(cityId, n)` | 单 city 起终点直线 Top N | "深圳最长规划线路 Top 5" |
| `getMetroPlanningGeoByCityStartEnd(cityId)` | 单 city 全部起终点坐标 + 直距 | "深圳 13 条线路坐标矩阵" |
| `getMetroPlanningGeoCrossCityByConfidence(level)` | 跨城同 confidence 对比 | "三城 manual 占比" |
| `getMetroPlanningGeoManualFallbackRate` | 跨城 manual 占比（数据完整性指标） | "深圳 70% manual vs 广州 30%" |
| `getMetroPlanningGeoByCityCrossReference` | 与 metro_planning.lineId 对齐 → 直距 vs 实际里程 + 弯曲系数 | "深圳 18 号线弯曲 1.5（绕盐田-光明）" |
| `getMetroPlanningGeoByCityMissingEndpoints(cityId?)` | 缺坐标的起/终点（confidence=missing 或 null） | "广州 8 号线北延待补坐标" |
| `getMetroPlanningGeoCoverageStats` | 全国端点坐标覆盖率（lat/lng 非 null + confidence ≠ missing） | "全国 41 端点中 33 完整 = 80%" |

## 关键决策

1. **Haversine 公式作为基础工具导出**：未来其他派生可直接复用，避免重复实现。
2. **弯曲系数 `actual / straight`**：
   - 1.0 = 完全直线（罕见）
   - 1.0~1.3 = 微弯（正常）
   - >1.3 = 严重弯曲（如绕开地形/老城区）
3. **5 confidence 阈值**：`high / medium / low / manual / missing` —— 派生层**只读**，
   不参与质量评级（让 upstream 决定）。
4. **cross-reference 按 lineId 对齐**：v0.15 metro_planning 和 metro_planning_geo 的
   lineId 完全对应（1-21），可直接 merge。
5. **`straightLineMeters` 返回 null 而非 0**：当任一端点缺失坐标时，明确"未计算"
   而非"0 距离"——避免污染平均计算。

**map-view** 页面加 "🚇 规划线路弯曲度" 卡（用 cross-reference + 直距 Top），让
用户直观看到哪些线路"绕远"。
