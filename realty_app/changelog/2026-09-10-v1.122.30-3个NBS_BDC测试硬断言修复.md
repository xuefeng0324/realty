# v1.122.30 — 修 3 个测试 month/year 硬断言（防御 cron monthly/quarterly 自动 commit 后 break）

**日期**：2026-09-10
**类型**：test（防御性维护，v1.122.29 续作）
**影响**：3 个 test files / 真读 csv 场景；下个 cron monthly/quarterly 自动 commit 后不会 break CI

## 问题根因

v1.122.29 修了10 个测试硬断言，但扫尾时发现**还有一批 month/year 硬编码**。本轮逐个 review，发现：

- `dailyWangqian.test.ts` / `metroPlanningRanking.test.ts` / `listingTrustSummary.test.ts` / `rules.test.ts` / `gzNewHouseInventory.test.ts` / `nbsIndustrial.test.ts` / `nbsTrade.test.ts` / `nbsPmi.test.ts` / `nbsIndustrialProfit.test.ts` —— **全是 mock 数据**（`setSnapshot` / 字符串内 mock CSV / 假数据），**不是真读 csv**，**不会受 cron 影响**。
- `educationOverview.test.ts` —— 硬断言 period="2025" / publishDate="2026-05-13" 等——年度源，**已 EXEMPT 候选**（不触发 cron 自动 commit），等用户拍板 EXEMPT。
- `lprHistoryAnalysis.test.ts` —— `setSnapshot` mock，但**生产代码用真实 csv import rawCsv**——mock 测试**不能发现真实 bug**（覆盖盲点，不是断言错误）。
- `nbsEnergy.test.ts` / `nbsRetail.test.ts` —— **真读 csv +硬断言 month="2026-06"**——下个 cron 16-20 号自动 commit 2026-07 月后会 break。**真 bug**。
- `zhBdcRegistration.test.ts` —— **真读 csv +硬断言 year=2026 quarter=2 + residentialUnits=3933**——下个季度自动 commit 2026Q3 后会 break。**真 bug**。

## 修了什么（3 files）

| 文件 | 旧断言 | 新断言 |
|------|--------|--------|
| `tests/nbsEnergy.test.ts:17-27` | `month === "2026-06"` + 8 个数值 toBe + shortNbsEnergyMonthLabel("2026-06") | `month regex /^\d{4}-(0[1-9]\|1[0-2])$/` + 8 个数值 `toBeGreaterThan / toBeLessThan` 范围 + shortNbsEnergyMonthLabel(latest.month) 验证格式 |
| `tests/nbsRetail.test.ts:15-25` | `month === "2026-06"` + 8 个数值 + 标签验证 | `month regex` + 数值范围 + 标签 regex |
| `tests/zhBdcRegistration.test.ts:26-49` | `year === 2026 / quarter === 2 / residentialUnits === 3933 / unitsDelta === 3933-2875` | `year regex / quarter regex / 数值范围 / unitsDelta = latest - prev 容差` |

## 修法（同 v1.122.29 / v1.122.19 pattern）

- month / year / quarter 改 regex（`/^20\d{2}-(0[1-9]|1[0-2])$/` / `>= 2020` / `1-4`）
- 数值断言改 `toBeGreaterThan / toBeLessThan` 合理范围（如煤产 2-6 亿吨、油产 1500-2200 万吨）
- 派生差分改 `toBeCloseTo(latest-prior, 1)` 容差 1（应对 cron 补数据微调）
- 派生比例 / formatXxxPeriod 输出验证改 regex 或范围
