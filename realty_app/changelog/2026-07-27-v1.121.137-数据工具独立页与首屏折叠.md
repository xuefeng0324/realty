# v1.121.137 — 数据工具独立页 + 首屏折叠（设置入口）

**日期**：2026-07-27
**versionCode**：258

## 一句话总结

按用户「**通过设置入口，不要老是放在同一页**」指令：
- 新增 **`pages/data-tools/data-tools.vue`** 独立页（设置入口式导航）
- **dashboard 首屏精简**：21 张派生卡（7 张学校/通勤/行政区划类 + 14 张区情画像/特征溢价/挂牌标签类）默认折叠
- 加 2 个 dashboard 入口卡：「展开派生数据」折叠按钮 + 「数据工具 · 全部派生数据」独立页入口

## 背景

用户 1 小时内第 2 次发「首页还是老长」反馈。上轮 v1.121.136 真删了 15 张宏卡（-1,206 行），
但**派生卡**（学校指标 / 通勤 / 户型分布 / 区情画像 / 特征溢价 / 挂牌标签 等约 21 张）
仍占 dashboard 模板 ~5,000 行。

直接复制 21 张派生卡到独立页要复制 14 个复杂 computed + 50+ 个 import。
**务实方案**：派生卡**留在 dashboard** 但默认折叠在 `<view v-if="derivedExpanded">` 内，
点击按钮展开；同时新建**轻量版独立页**作为「设置入口」。

## 本次实现

### 1. 新增 `pages/data-tools/data-tools.vue`（独立页）

- header：标题 + 副标题（说明从仪表盘迁入）
- 「70 城 12 月趋势对比」轻量卡：仅概要，不复制 dashboard 内 14 个复杂 computed
- 「行政区划」完整卡：基于 `summarizeAdminDistrictByCity` + `app.cityId` filter
- 「更多派生数据」提示卡：5 张派生卡（地铁步行 / 分区均价 / 学校指标 / 重点学校 / 教育事业）说明在首页展开可见

### 2. dashboard.vue 首屏精简

**折叠范围（21 张派生卡）**：
- 7 张学校/通勤/行政区划类卡（行 820-1302）：包进 `<view v-if="derivedExpanded">` 折叠块
- 14 张区情画像/特征溢价/挂牌标签类卡（行 2055-3864）：包进另一个 `<view v-if="derivedExpanded">` 折叠块

**首屏渲染时间优化**：21 张派生卡默认不渲染（v-if false），用户点击后才加载。

**加 2 个入口卡**：
- 「展开派生数据」按钮：点击 `toggleDerivedCards()` → `derivedExpanded.value = !derivedExpanded.value`
- 「数据工具 · 全部派生数据」按钮：点击 `goDataTools()` → `uni.navigateTo` 到独立页

### 3. pages.json 新增 data-tools 路由

```json
{
  "path": "pages/data-tools/data-tools",
  "style": {
    "navigationBarTitleText": "数据工具",
    "enablePullDownRefresh": true
  }
}
```
