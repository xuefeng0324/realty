# v1.122.0 — 移动端全量改版与 CI 告警治理

## 背景与对照

- 移动端原入口层级过深，首页同时承载检索、行情、宏观与专业工具，用户难以判断下一步。
- 设计对照采用成熟房产与生活服务 App 的“原生一级 Tab + 聚合二级入口 + 明确数据口径”结构，不复制品牌素材或业务文案。
- 每日邮件告警的主要根因分别是：网签 workflow 参数与脚本默认值漂移；70 城在正常发布窗口过早置红；weekly 用 `|| true` 静默吞错且缺少分源证据；E2E 还受到开发态 Eruda 浮层遮挡底栏点击。

## 用户可见改动

1. 原生一级入口调整为“首页 / 找房 / 地图 / 行情 / 我的”，旧学校路由继续支持深链。
2. 新增行情聚合页，按本地、全国、宏观、工具四组承接网签、70 城、供需、五个宏观页、趋势与数据工具。
3. 首页收敛为城市、搜索、核心市场脉搏、五个快捷入口和推荐房源；用 `LEGACY_DASHBOARD_MIGRATIONS` 锁定 28 项旧能力的 7 个去向。
4. 找房页统一房源、小区、学校三种模式；地图与详情、收藏、“我的”形成完整闭环。
5. 新增版本化 `UserLibraryV1`：以 `type:id` 去重，仅保存轻量跳转信息；历史最多 100 条、90 天，损坏或未知版本安全回空。
6. 22 个移动端路由统一翡翠绿 + 科技蓝 token、浅/深主题、共享壳层/页头/分段 Tab/Bottom Sheet/指标卡/列表/异步状态；桌面端未改。
7. 开发态 Eruda 改为显式 `?eruda=1` 才加载，避免右下角浮标遮挡原生 TabBar；首页推荐区补足底部安全区并限制封面命中层。

## CI 与数据安全

1. daily 网签抓取默认 merge；隐藏 `--merge` 保持旧调用兼容，只有 `--no-merge` 才重写当前窗口。
2. 主题壳 API 保持 `applyTheme()` 同步返回，同时吸收原生 API 的同步异常与 Promise rejection，不过滤浏览器错误。
3. 70 城整表先写同目录临时文件，校验每月同比/环比各 70 城、字段数值、重复项、月份倒退和历史截断后原子替换。
4. 70 城新鲜度新增 `fresh / waiting / stale / missing`，保留 `fresh: boolean`；16–19 日缺上月仅 warning，20 日仍落后才失败，缺失/损坏/落后两月始终失败。
5. weekly 拆为 P0 挂牌核心硬失败、P1 必需来源全部执行后统一失败、P2 非核心来源 warning；统一 runner 为每个来源保存日志、TSV 和 Job Summary，编排异常独立置红，不再使用静默 `|| true`。
