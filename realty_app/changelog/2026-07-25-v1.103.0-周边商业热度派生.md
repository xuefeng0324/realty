# v1.103.0 周边商业热度派生（仅数据层）

## 目标

复用既有 v0.19.0 完整链路（`community_commercial.csv` → `LocalCommunityCommercial` → snapshot，**链路已完整**），新增 5 个高阶派生函数，让"周边商业到底多方便"这个问题在数据层就绪。

## 数据

`community_commercial.csv`（42 行 × 11 字段）

| 字段 | 含义 |
|---|---|
| community_id | 小区 |
| city_id, district_name, community_name | 城市 / 区 / 小区 |
| restaurant_count / bank_count / convenience_count | 3 类 POI 计数 |
| nearest_restaurant_m / nearest_bank_m / nearest_convenience_m | 3 类 POI 最近距离（米，**可 null**） |
| commercial_score | 综合商业分（0-100） |

## 派生

`src/local/communityCommercialRanking.ts`（5 函数）：

1. `summarizeCommunityCommercialByCity` —— 按 city 聚合（小区数 / 各 POI 平均 count / 平均距离 [null 安全] / 平均 score）
2. `getCommunityCommercialByScoreTopN(cityId|null, n)` —— 商业分 Top N
3. `getCommunityCommercialByNearest(poiType, cityId|null, n)` —— 单 POI 类型（restaurant/bank/convenience）最近小区榜；null 距离过滤
4. `getCommunityCommercialByCityDistrict(cityId?)` —— 按 city × district 聚合（含 rankOverall 1-based 排名）
5. `getCommunityCommercialDensityVsDistance(poiType, densityThreshold, distanceThreshold)` —— 密度/距离悖论 4 桶：[高密度近, 高密度远, 低密度近, 低密度远]；空 snapshot 仍返回 4 个空 bucket 保持顺序
