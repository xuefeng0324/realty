# v1.123.73 · 设计体系统一

## 背景

用户反馈「UI 没有设计理念、很多地方跟大众审美不一致、设计不统一」。本轮先横向对照四套公认设计体系（Material 3 8dp 间距与角色色、Apple HIG 字号层级与最小可读字号、Ant Design 8/16/24 亲密度与克制用色、Refactoring UI 灰度优先与受约束尺度），形成一条可执行的章程：

- **克制、清晰、可信**：单一品牌绿承担所有主操作；蓝色只留给数据可视化。
- **8rpx 间距体系**：间距只用 `--space-1..8`，不再出现 10/14/18/22rpx 等长尾。
- **受约束字号**：8 档（22 / 24 / 26 / 28 / 32 / 36 / 40 / 52rpx），不再出现 20/23/25/27/29/30/31/34/38/44rpx。
- **圆角与阴影**：4 / 8 / 12 / 16 / 24 / pill；卡片统一 24rpx + `--shadow-card`。
- **层级靠字号字重与留白**，不靠装饰色和 emoji。
