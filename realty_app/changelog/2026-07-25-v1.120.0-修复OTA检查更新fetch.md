# v1.120.0 · 修复 OTA 检查更新（fetch is not a function）

**日期**：2026-07-25  
**类型**：bugfix（OTA / 设置页）

## 现象

真机设置页「检查更新」报错：

```text
检查失败: 无法访问更新服务器: fetch is not a function
```

同时「政府在线查询」卡片备注显示为 `[object Object]`。

## 根因

1. `src/utils/appUpdate.ts` 用了浏览器全局 `fetch`。App-Plus（Android WebView /
   HBuilder 基座）通常**没有** `fetch`，直接抛 `fetch is not a function`。
2. `settings.vue` 把整个 `GOV_WEB_LINKS.szPortal` 对象插进模板，被 `toString`
   成 `[object Object]`；应取 `.note`。

## 修复

- `checkAppUpdate` 改为 `uni.request` 拉清单（与 `remoteFetch.downloadText` 同口径）
- 多 CDN 镜像回退：`UPDATE_BASE_URL` + `getStaticBases()` 的 `/update/app-update.json`
- 命中镜像后，把清单里写死的 `cdn.jsdelivr` wgt URL 改写到同一镜像
  （`rewriteWgtUrlToBase`）
- 设置页备注改为 `govLinkNotes.szPortal.note`

## 重要：鸡生蛋问题

当前手机上的 `v0.92.0` **本身**就无法完成检查更新，因此**无法靠 OTA 自动装上本修复**。
需要先用下面任一方式装一次带修复的包：

1. **HBuilderX 重新运行到手机**（截图包名 `io.dcloud.HBuilder` = 标准基座）
2. 或等 CI 产出 APK/WGT 后，从 GitHub Releases / `static/update/<code>/app.wgt` 手动安装

装上 `1.120.0` 之后，以后的 OTA「检查更新」即可正常使用。
