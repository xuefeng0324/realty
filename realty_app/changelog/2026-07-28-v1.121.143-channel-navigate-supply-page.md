# v1.121.143 — 频道/金刚跳独立页 + 供需页

## 问题

总览顶部已有「房价 · 网签 · 宏观 · 供需 · 配套 · 工具」频道与金刚区，但多数只做本页 `scrollIntoView`，用户仍要滚很长的信息流；与「分类入口 = 独立页、缩短首页」的产品要求相反，也与「不要搞折叠那一套」冲突。

## 改动

1. **`homeEntry.ts`**：`HOME_CHANNELS` 全部改为 `navigate` / `switchTab` / `tab`；金刚「库存」「土地」→ `/pages/supply/supply`；本页关键词搜索同步改为跳页。
2. **新建 `pages/supply/supply.vue`**：供需与土地独立页（广州库存分区明细默认展开、深圳计划入市、珠海安居、广深土地）。
3. **`dashboard.vue`**：`onHomeChannel`；供需/土地等卡 `data-tab="archived"` 移出概览；宏观/网签/LPR/学区预览卡去掉 overview。
4. **文档/测试**：更新 `DASHBOARD_ENTRY_IA.md`、`FEATURE_CATALOG`、`homeEntry` / budget / smoke_entry_supply / buildIntegrity。

## 验收标准

| 类型 | 期望 | 不期望 |
|------|------|--------|
| UI | 点频道离开总览进入对应页；供需页有标题与 KPI | 点了还停在总览长滚 |
| 功能 | 工具→data-tools；供需/库存→supply；宏观→macro-region | 空跳、白屏 |
| 逻辑 | 入口配置集中 `homeEntry.ts`；不误标成交均价 | 硬编码散落 |
