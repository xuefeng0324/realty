# v1.121.132 — 3 个 macro 子页 MacroKpiCell 铺开

**日期**：2026-07-27  
**类型**：patch  
**versionCode**：253

## 背景

v1.121.131 抽 `MacroKpiCell.vue` 单 KPI 单元格组件后，本轮把组件铺到全部 3 个 macro
子页（macro-region / macro-industry / macro-trade）共 52 个 KPI 上，替换原重复
`<view class="stats70-cell">…</view>` 三层模板。

| 子页 | v1.121.131 | 本轮目标 | 收益 |

## 关键改动

### 1. macro-trade.vue（4 KPI）

`进出口当月 / 累计 / 出口当月 / 进口当月 / 当月顺差` 全部改用 MacroKpiCell。
`muted` 副文本通过 `subClass="muted"` 传入；同比配色通过 `subTrendClass` 传入。
**134 → 90 行（-44 / -32.8%）**。

### 2. macro-region.vue（16 KPI，4 张卡 × 4）

`gdRealEstateBrief / gdEconomy / gdFaInvestment / gdConstruction` 4 张宏卡共 16 个 KPI
改用组件。import 由 `macroTrendClass` 替换为 `macroTrendBand`。
**369 → 335 行（-34 / -9.2%）**。

### 3. macro-industry.vue（32 KPI，8 张卡 × 4）

`nbsFaInvestment / nbsIncome / nbsCpi / nbsPmi / nbsIndustrial / nbsIndustrialProfit /
nbsPpi / nbsRetail` 8 张宏卡共 32 KPI 改用组件。**首例引入 `pmiVsThreshold(nbsPmi.mfgPmi)`
嵌套括号 toBand 解析**，脚本改用括号深度匹配。nullable 守护
`nbsIndustrialDelta?.yoyDeltaPp ?? 0` / `nbsIndustrialProfitDelta?.marginDeltaPp ?? 0`
补全，避免 TS18047。**766 → 599 行（-167 / -21.8%）**。

### 4. `utils/format.ts`

`macroTrendBand(v)` 已在 v1.121.131 新增，本轮被 3 个子页统一使用。
