# v1.121.8 — 离线包 OTA 自检加固（zip4j + install-apk + 审计脚本）

## 背景

v1.121.7 整包已补 zip4j，但复盘发现 simpleDemo 还漏了官方 `install-apk-release.aar`，
且此前没有「出包前自动拦已知坑」的检查，导致 100% 闪退这类问题要靠用户真机撞出来。

## 本版改动

1. 拷入 `install-apk-release.aar` / `uni-installApk-release.aar`；Manifest 显式 `REQUEST_INSTALL_PACKAGES`
2. `build_apk_local.ps1`：缺 aar 自动从 `SDK/libs` 补齐；**审计失败拒绝出包**
3. 新增 `scripts/audit_offline_pack.mjs`（zip4j / aar / appkey / 远程 wgt zip+sha）
4. `appUpdate.ts`：下载前创建 `_doc/update` 目录

## 验证（本机已跑）

```text
node scripts/audit_offline_pack.mjs  → PASS (16 ok)
node scripts/verify_ota.mjs --local-code=126 → PASS (126→127)
vitest openExternal+appUpdate → 20/20
APK dex 含 net/lingala/zip4j
```

## 用户动作

重装桌面 `RealtyApp-1.121.8-129.apk`（不要用旧 126/无 zip4j 包再试 OTA）。
