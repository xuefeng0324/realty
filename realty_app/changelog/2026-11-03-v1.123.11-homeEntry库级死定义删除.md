# v1.123.11 删除 homeEntry.ts 库级死定义（HOME_CHANNELS / HOME_KINGKONG 等）

## 背景

v1.123.10 删掉旧 `home-entry-card` 死 DOM（v1.121.83 F-ENTRY-01 遗产，v1.122 起被壳层 CSS 永久隐藏）后，`src/local/homeEntry.ts` 中的频道条 / 金刚区库定义已无任何 UI 或脚本消费者——全仓 grep 确认 `HOME_CHANNELS` / `HOME_KINGKONG` / `homeKingkongCount` 及关联类型仅剩 `homeEntry.test.ts` 库级自测引用。本轮将其删除，属于上轮死 DOM 清理的库级收尾。

## 删除

- **`src/local/homeEntry.ts`**：
  - 常量：`HOME_CHANNELS`（6 项频道条）、`HOME_KINGKONG`（11 项金刚区）；
  - 函数：`homeKingkongCount()`；
  - 类型：`HomeChannel` / `HomeKingkongItem` / `HomeChannelKey` / `HomeEntryTone` / `HomeKingkongAction` / `HomeChannelAction`。

## 保留（仍有真实消费者）

- `HOME_SEARCH_MODES` / `resolveHomeSearch` / `HomeSearchMode` / `HomeSearchResolve`：dashboard v122 壳层搜索消费；
- `resolveHomeScrollAnchor` / `HomeScrollAvailability` / `HomeScrollResolve` / `homeSupplyEntryOwner` / `homeLandEntryOwner`：壳层锚点解析（`jumpHomeAnchor` / `supplyEntryOwner` / `landEntryOwner`）消费；
- `setPendingFindMode` / `takePendingFindMode` / `FindHubMode` / `setPendingSchoolQuery` / `takePendingSchoolQuery` / `setPendingListingQuery` / `takePendingListingQuery`：dashboard / listing-filter / school 跨页 pending 消费。
