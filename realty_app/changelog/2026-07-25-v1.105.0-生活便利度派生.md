# v1.105.0 生活便利度派生（仅数据层）

## 目标

复用既有 v0.31.0 完整链路（`life_convenience.csv` → `LocalLifeConvenience` → snapshot，**链路完整**），新增 6 个高阶派生函数，让"小区综合便利 vs 单维度失衡"在数据层就绪。

## 数据

`life_convenience.csv`（44 行 × 12 字段）

| 字段 | 含义 |
|---|---|
| community_id / city_id / district_name / community_name | 小区坐标 |
| mallNear / parkNear / subwayNear / schoolNear / hospitalNear / marketNear | 6 类 POI 近数 |
| score | 综合分（0-110，6 类加权求和） |
| score100 | 归一化（0-100，score/110×100） |

## 派生

`src/local/lifeConvenienceRanking.ts`（6 函数）：

1. `summarizeLifeConvenienceByCity` —— city 聚合（小区数 / 各 POI 平均近数 / 平均 score100 / city 最高分小区）
2. `getLifeConvenienceTopByScore(cityId|null, n)` —— score100 Top N
3. `getLifeConvenienceByCityDistrict(cityId?)` —— 区分聚合 + rankOverall 排名
4. `getLifeConvenienceByDimensionCoverage(dim, n)` —— 全量按某维度近数倒序 Top N（看哪个小区某 POI 最多）
5. `getLifeConveniencePareto(dim, minScore100, n)` —— "score ≥ X + 某维度最强" Pareto 榜
6. `getLifeConvenienceDimensionBalance(scoreThreshold, dimThreshold, n)` —— **失衡检测**：score100 < X 但 strongestValue > Y 的小区（"伪便利"）
