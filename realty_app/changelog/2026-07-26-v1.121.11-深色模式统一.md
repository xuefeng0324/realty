# v1.121.11 — 深色模式界面统一

## 问题

深色模式下大量区块仍是浅灰/白底，uni-app 默认 `button` 也是浅色，整体不协调。

## 改动

1. `App.vue` 扩展主题 token：`--color-soft` / `--color-panel` / soft 语义色等；浅色主题同步覆盖
2. 全局覆盖 uni `button` 默认浅底；`.btn` / `.btn-ghost` 跟 token
3. 仪表盘、小区、房源详情、筛选、地图等页：硬编码 `#f1f5f9`/`#f8fafc`/`#e2e8f0` 等改为 CSS 变量
4. `theme.ts`：原生端同步导航栏/TabBar；页面根节点打 `data-realty-theme`

- `vue-tsc`：通过
