### 2. 5 个 inline helper

- `formatForexYi(v)` — "x,xxx 亿$"（储备/成交数据）
- `formatPctDelta(v)` — "+x.xx%" / "-x.xx%"（环比百分比）
- `formatDelta(v)` — "+x.xx" / "-x.xx"（绝对变动）
- `bandFromDelta(v)` — "up"|"down"|"flat"（供 MacroKpiCell.subTrendClass）
- `safeOraPct(part, total)` — "x.x"（官方储备资产分项占比）

### 3. 字段名校正

macro-fx 卡片初期按 v0 时期 dashboard 字段命名写，TypeScript 提示真实字段名差异：

| 我写 | 实际 | 备注 |
|------|------|------|
| `midPrice` | `usdCny` | safeUsdMid |
| `deltaBp` | `delta` | getSafeUsdMidDeltaVsPrev 返回 `{prev, delta}` |
| `spotUsdYi / forwardUsdYi / swapUsdYi` | `totalUsdWanYi / spotRmbWanYi / derivativeRmbWanYi` | safeFxMarket 单位是**万亿元**非亿美元 |
| `settlementUsdYi / salesUsdYi / netUsdYi` | `settleUsdYi / sellUsdYi / surplusUsdYi` | safeSettle 字段少一个 t |
| `currentUsdYi / capitalUsdYi / financialUsdYi / netErrorsUsdYi` | `currentAccountUsdYi / capitalFinancialUsdYi / goodsSurplusUsdYi / servicesSurplusUsdYi / ...` | safeBop 综合字段 |
| `assetUsdYi / liabilityUsdYi` | `assetsUsdYi / liabilitiesUsdYi` | safeIip 复数 s |
| `serviceExportUsdYi / serviceImportUsdYi` | `servicesExportUsdYi / servicesImportUsdYi` | safeBopTrade 复数 s |
