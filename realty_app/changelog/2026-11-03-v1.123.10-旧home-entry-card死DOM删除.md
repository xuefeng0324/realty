# v1.123.10 旧 home-entry-card 死 DOM 删除

## 背景

v1.122 首页收敛为新版壳（`.home-v122-shell`）后，壳层 CSS 对非壳层直子级统一 `display:none!important`，首屏只露出 v122 壳。旧 `home-entry-card`（v1.121.83 F-ENTRY-01 的城市 chip + 搜索 + 频道横滚 + 金刚区）与 v122 壳功能完全重复，自此一直作为不可见死 DOM 留在页面里，且与壳层共享 `data-home-city` / `data-home-search` / `data-home-mode` / `data-home-king` / `data-home-kingkong` 等选择器，形成双份匹配隐患。

## 删除

- **模板**：`home-entry-card` 整块（约 55 行）——城市 chip、搜索框、搜索模式 chip、`HOME_CHANNELS` 频道横滚、`HOME_KINGKONG` 金刚区。
- **脚本**：`onHomeChannel` / `onHomeKingkong` 两个动作分发函数；`HOME_CHANNELS` / `HOME_KINGKONG` / `type HomeChannel` / `type HomeKingkongItem` 孤儿 import。
- **CSS**：`.home-entry-card` / `.home-loc-search` / `.home-city-chip(::after)` / `.home-city-name` / `.home-city-caret` / `.home-search` / `.home-search-input` / `.home-search-btn` / `.home-search-modes` / `.home-mode-chip(--on)` / `.home-channel-scroll` / `.home-channel-row` / `.home-channel-chip` / `.home-kingkong` / `.home-king-tile` / `.home-king-icon`（含 7 个 tone 变体）/ `.home-king-label` / `.home-entry-hint`，共 20 组。
- **孤儿 e2e**：`tests/e2e/smoke_entry_supply.mjs`——点击目标（隐藏金刚「库存」/频道「工具」）本已不可见，且不在 core/extended 任何 suite。

## 保留（仍被消费，行为不变）

- `src/local/homeEntry.ts` 库定义：`HOME_CHANNELS` / `HOME_KINGKONG` / `HOME_SEARCH_MODES` / `resolveHomeSearch` / `resolveHomeScrollAnchor` 等（`homeEntry.test.ts` 库级断言全部保留在测）。
- dashboard 内：`submitHomeSearch` / `jumpHomeAnchor` / `homeScrollAvailability` / `supplyEntryOwner` / `landEntryOwner`（壳层搜索 scroll 分支与 `entry-supply` / `entry-land` 锚点仍消费）、`pickCity`、`onHomeSearchInput`。

## 测试同步

- `homeEntry.test.ts`：删 dashboard 源码对 `HOME_KINGKONG` / `onHomeChannel` / `onHomeKingkong` 的失效断言与被删 smoke 的引用；`data-home-entry` / `data-home-search` / `data-home-kingkong` 断言保留（v122 壳仍含）。
- `buildIntegrity.test.ts`「v0.55.0 hero-1」：删 `HOME_KINGKONG` / `function onHomeKingkong` 两条失效断言。
- `uiVerticalAlign.test.ts`：两条垂直居中守卫从已删的 `.home-search-input` / `.home-search-btn` 改指 v122 壳 `.home-v122-search-input` / `.home-v122-search-btn`；对应 CSS 补 `box-sizing: border-box` 与 flex 居中（视觉不变）。
- `dataToolsEntry.test.ts`「精简模式在设置页」：追加 v1.123.10 禁出现门禁（`home-entry-card` / `home-king-tile` / `onHomeChannel` / `HOME_CHANNELS` / `.home-search` 等）。
- layout 基线随 DOM 删除重生成（`smoke.mjs` + `layout-diff.mjs --update-baseline`）。
