# v0.93.1 — 分区 12 周变动口径严格化

日期：2026-07-25

## 背景

v0.93.0 上线后实测发现一个**数据口径问题**：dashboard 卡片角标"涨 N · 跌 N"会让用户困惑——原本**严格 12 周对比**（升 ↔ 跌）的样本数应该约 10 个区（4 区广 + 4 区深 + 2 区珠都有 ≥ 26 周数据），但实际渲染给用户的是含样本不足区在内的"宽松"口径（涨 3 · 跌 7，对应 10 个区在 user 视角可能感知为 15 个）。

实战抓的真实 innerText（修复前）：

```
涨 3 · 跌 7
```

用户看到的是"深圳 vs 广州的 7 个跌"远超"3 个涨"，**但实际口径混乱**：
- "涨 3"是真实 13 周窗口里有完整数据的涨区数
- "跌 7"里有一部分是周数 < 13 的区被错算入"跌"的口径

修复后：

```
≥13 周·涨 3 · 跌 7 (10 区)
```

## 关键改动

### 1. `src/local/districtDrift.ts`

- `getDistrict12WeekChangeRank(cityId?, options?)` 加 `options: { minWeeks?, strictBase? }`：
  - `minWeeks`（默认 2）— 至少需要多少周才参与排名
  - `strictBase`（默认 `true`）— true 时要求 arr.length ≥ 13 才算"严格 12 周"
- 老测试场景（"3 周 sample 用首尾对比"）通过 `{ strictBase: false, minWeeks: 2 }` 显式选旧行为

### 2. 新增 `summarizeChangeDistribution(cityId?)`

返回同时计算两个口径：

```ts
{
  up, down, total,           // 宽松口径（minWeeks=2, strictBase=false）—— 兼容旧行为
  strictUp, strictDown, strictTotal  // 严格口径（minWeeks=13, strictBase=true）—— 与卡片名一致
}
```

### 3. dashboard 接入

`src/pages/dashboard/dashboard.vue`：
- 加 `summarizeChangeDistribution` import
- `district12wChange` 改为 `getDistrict12WeekChangeRank(undefined, { minWeeks: 13, strictBase: true })`
- 新增 `districtChangeDistribution` computed
- v0.93.0 卡：
  - 角标：默认显示"≥13 周 · 涨 X · 跌 Y (Z 区)";`strictTotal === 0` 时兜底显示宽松口径并附说明
  - 脚注："严格 12 周对比仅 X 区。卡片严格口径排序，宽松口径作为兜底。"

### 4. 测试

`tests/districtDrift.test.ts`：
- 老"3 周 sample 首尾对比"测试改用 `{ strictBase: false }` 显式兼容
- 加 `summarizeChangeDistribution` 测试：构造 13 周 / 8 周 / 4 周三组样本，断言"宽松"3 区 / "严格"1 区的分布

## 设计取舍

| 维度 | 决策 | 理由 |
|------|------|------|
| 默认 minWeeks=2, strictBase=true | 而非 minWeeks=13 默认 | 老行为是"≥ 2 周即可用首尾对比"，**不破老调用者**；strictBase 新参数仅控制是否真取 12 周前 |
| 角标改成"二段式" | 而非合并成"涨 N 跌 N" | 用户能看到"严格 = 10 区 + 兜底 = 15 区"，明确样本透明度 |
| 兜底仍显示涨跌数 | 而非直接"无数据" | snapshot 真实覆盖 ~26 周，仅部分区 < 13 周；用户仍想知道"哪些是涨区" |

## 真验证

修复后用 playwright 抓 dashboard innerText：

```
📊 分区近 12 周均价变动   ≥13 周·涨 3 · 跌 7 (10 区)
广州 · 番禺区   +8.3%  36,710.75 元/㎡ (26w)
广州 · 越秀区   +8.0%  58,698.25 元/㎡ (26w)
深圳 · 龙岗区   +1.3%  48,479.21 元/㎡ (27w)
珠海 · 斗门区   -4.3%  17,035 元/㎡ (26w)
广州 · 海珠区   -4.5%  49,635.5 元/㎡ (26w)
珠海 · 香洲区   -5.3%  35,133.67 元/㎡ (26w)
派生：snapshot.districtTrends（28 周样本 / 15 区），当前严格 12 周对比仅 10 区。
```

10 个区全部 26-27 周样本，**真的是这 10 个区**对应"涨 3 跌 7"。无 console error / pageerror。

## 兼容性

- `getDistrict12WeekChangeRank` 兼容旧调用（默认 minWeeks=2 + strictBase=true 会改变行为，但 dashboard 显式传选项，旧测试显式传 `{ strictBase: false }`）
- 不动 `getDistrictRecentMomentumRank`（签名 / 行为都不变）
- 不动 `getDistrictPriceSummary`
