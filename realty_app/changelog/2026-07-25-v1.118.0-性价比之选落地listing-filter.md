### 动态价格上限设计

```ts
const paretoPriceCapWan = computed<number>(() => {
  const allScatter = getCommunityScatter();
  // 取当前城市 "改善(60-110)" 面积段所有社区的中位数 × 1.5
  const cityRows = allScatter.filter(
    (r) => r.cityName === currentCityName && r.areaCohort === "改善(60-110)"
  );
  const sorted = cityRows.map(r => r.medianUnitPrice).sort();
  const median = sorted[Math.floor(sorted.length / 2)];
  return Math.round((median * 1.5) / 10000);  // 元/m² → 万/m²
});
```

**为什么动态化？** 深圳均价 6-7 万/m²，广州 3-4 万，珠海 1-2 万。固定 8 万/m² 上限会让
珠海"刷不出"推荐；动态化让三个城市都能给出"改善段下面积较大"的小区。
