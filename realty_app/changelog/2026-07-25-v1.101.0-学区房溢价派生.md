# v1.101.0 学区房溢价派生（仅数据层）

## 目标

复用既有 v0.17.0 完整链路（`listing_school_premium.csv` → `LocalListingSchoolPremium` → snapshot，**链路已完整**——types/snapshotLoader/store 都有，只是没有"列出过"），新增 5 个高阶派生函数，让"学区房到底值不值"这个问题在数据层就绪。

## 数据

`listing_school_premium.csv`（1278 行，每 listing 一行）

| 字段 | 含义 |
|---|---|
| listing_id | 主表 listing.id |
| city_id | 城市 |
| district_name | 区 |
| community_id | 小区 |
| school_count | 周边学校数 |
| avg_school_score | 周边学校平均分（0-100） |
| **premium_ratio_est** | (本 listing 单价 / 同区非学区房中位 - 1) × 100 的预估值 |

样例：`南山区, 86.3, 23.16` —— 南山区某 listing 周边 4 所学校平均 86.3 分，预估学区房溢价 23%。

## 派生

`src/local/listingSchoolPremiumRanking.ts`（5 函数）：

1. `summarizeListingSchoolPremiumByCity` —— 按 city 聚合（listing 数 / 有溢价 listing 数 / 平均溢价 / 高溢价（>10%）占比 / 城市溢价 Top listing）
2. `aggregateListingSchoolPremiumByCommunity(cityId?)` —— 按 community 聚合（avg + top listing）；无 cityId 时跨城
3. `getListingSchoolPremiumByCommunityLeaderboard(cityId|null, n)` —— 学区溢价榜 Top N（按 community 平均溢价）
4. `getListingSchoolPremiumByCityDistrict(cityId?)` —— 按 city × district 聚合（listing 数 / community 数 / 平均溢价 / 高溢价占比）
5. `getListingSchoolPremiumDistribution(cityId?)` —— 4 桶分布 [≥30%, 10-30%, 0-10%, <0%]（含 count + share）
