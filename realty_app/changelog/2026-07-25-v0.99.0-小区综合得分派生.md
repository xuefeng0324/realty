# v0.99.0 小区综合得分派生（仅数据层）

## 目标

复用既有 v0.33.0 完整链路（`community_score.csv` → `LocalCommunityScore` → snapshot），新增更高阶派生函数，让"住哪方便 / 学区强 / 通勤快"的三维指标在数据层就绪，等待社区详情 / listing-filter 等 UI 接入。

## 数据

| 字段 | 来源 | 样例 |
|---|---|---|
| community_id | community 主表 | 14 |
| city_id | city 主表 | 1 |
| district_name | 区 | 越秀区 |
| community_name | 小区 | 北京路名宅 |
| life_score | 生活便利 (0-100) | 95.5 |
| school_score | 学区 (0-100) | 85.2 |
| commute_minutes | 到 CBD 分钟（无则 null） | 27 |
| commute_score | 通勤分 (0-100) | 100 |
| total_score | 综合加权 (0-100) | 93.3 |
| rank_city | city 内排名（1-based） | 1 |

## 派生

`src/local/communityScoreRanking.ts` 新增 5 个函数：

1. `summarizeCommunityScoreByCity` —— 按城市聚合（小区数 / 4 维均值 / 平均通勤分钟，null 安全）
2. `getCommunityScoreByTotalTopN(cityId|null, n)` —— 总分榜（按 city 过滤或跨城）
3. `getCommunityScoreByDimensionTopN(dim, cityId|null, n)` —— life / school / commute 三维度榜
4. `getCommunityScoreByCommuteFastest(cityId|null, n)` —— 通勤分钟最快榜（null 自动排到末尾）
5. `getCommunityScorePareto(cityId|null, minTotal, n)` —— "总分 ≥ 阈值 + 通勤最快" 双目标榜
