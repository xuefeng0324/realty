# v0.94.0 — 学校指标各维度 Top 5 + 趋势涨跌（dashboard mini 卡）

日期：2026-07-25

## 目标

`school_indicators.csv` 已有 60 所学校 × 5 个维度（综合排名分 / 集团校标记 / 集团实力 / 区域均衡度 / 趋势变化），但 dashboard 与 school 页都只能"按综合排名查学校"，**没有跨维度对比**。

v0.94.0 把已有的 60 行 × 5 维度派生出：

- **每维度 Top 5**：综合 / 集团校实力 / 区域均衡度 各 Top 1 摘要 + Top 5 排序能力
- **趋势涨跌**：上升 / 下滑各 Top 5（按 trendDeltaRaw 排序）
- **总览统计**：综合 ≥ 90 达标率 + 集团校覆盖率 + 上升 / 下滑 / 不变计数

全部走新增的 `store.getSchoolIndicators()`，零抓虫。

## 数据源

| 字段 | 用途 |

| `static/seed/school_indicators.csv` | 60 行 / 学校 5 维度 |
| `local/types.ts` 的 `LocalSchoolIndicator` | 已存在 |

## 关键改动

### 1. `src/local/store.ts`

- import 加 `LocalSchoolIndicator`
- 新增 `getSchoolIndicators(): LocalSchoolIndicator[]`

### 2. `src/local/schoolIndicatorRanking.ts`（新增）

三个公开函数 + 两个类型导出：

- `summarizeSchoolIndicators()` → `SchoolIndicatorSummary { total, highLevelRate, groupSchoolRate, risingCount, decliningCount, flatCount }`
- `getSchoolIndicatorDimensionTopN(dimension, n=5)` → 通用维度 Top N
  - 支持三个维度：`latestLevelScoreRaw` / `groupSchoolStrengthRaw` / `districtBalanceLevelRaw`
  - null 值过滤
- `getSchoolIndicatorTrendTop(mode, n=5)` → "rising" / "declining" 两个模式
  - rising：`trendDeltaRaw > 0` 的降序
  - declining：`trendDeltaRaw < 0` 的升序
  - 排除 0 与 null

类型导出：`SchoolIndicatorRankingEntry`、`SchoolIndicatorSummary`、`SchoolIndicatorTrendEntry`、`SchoolIndicatorDimension`、`LocalSchoolIndicator`（让 dashboard / 测试复用）。

### 3. dashboard 接入

`src/pages/dashboard/dashboard.vue`：

- 新 import + 6 个 computed：`schoolIndicatorSummary` / `schoolTopLevel` / `schoolTopGroup` / `schoolTopBalance` / `schoolTrendRising` / `schoolTrendDeclining`。
- 新卡片「🎓 学校指标 · 各维度 Top 5」插在 v0.93.0 分区卡后、v0.81.0 NBS 卡前：
  - 顶部三栏 grid：综合排名 / 集团校实力 / 区域均衡度 各 Top 1 (schoolId + score)
  - 角标：综合 ≥ 90 达标率 + 集团校覆盖率（百分比）
  - 副卡：上升 Top 3 + 下滑 Top 3，延续 v0.91.0 / v0.92.0 / v0.93.0 的 `drift-row` 行样式 + `drift-up` / `drift-down` 颜色
  - 脚注：自解释 (60 所学校样本，仅显示 schoolId 而非名称：避免引入新维度"学校名缓存")

### 4. 测试

`tests/schoolIndicatorRanking.test.ts`：4 个用例

- `summarizeSchoolIndicators` 综合计算（达标率 / 集团校占比 / 涨跌计数 / 不变计数 / null 跳过）
- `getSchoolIndicatorDimensionTopN` 多维度（综合 / 集团校 / 均衡度），含 null 过滤
- `getSchoolIndicatorTrendTop` rising / declining 模式，分别按降序 / 升序
- 空 snapshot 安全降级

## 设计取舍

| 维度 | 决策 | 理由 |
|------|------|------|
| Top 卡片仅显示 schoolId | 不查 `getSchoolById()` 拼名称 | `schoolIndicators.csv` 没存学校名称，要展示需在 dashboard 多加 `schoolsByCity` / `schoolById` 二次跳转，与 v0.91.0 / v0.92.0 风格保持简洁；学校名点进 school 页就能看到 |
| 三维 max 用 grid 三栏 | 而非一张排行榜 | dashboard 单卡上限是"3 摘要 + 列表 + 脚注"，与 v0.93.0 节奏一致 |
| 趋势值用 `+/-X.XX` | 不 `formatPct` | trendDeltaRaw 是绝对分差（非比例），保留符号更直观 |
| rising / declining 用同函数 mode 切换 | 而非两个分离函数 | 公共逻辑只在 sort 方向上不同，复用减少漂移 |
| 通用维度（union） | 而非 3 个独立函数 | 类型收敛 + 测试一次性覆盖三个字段 |

## 兼容性

- `store.getSchoolIndicators()` 是**追加**导出，已有 `getIndicatorsBySchool()` 保留
- dashboard 新卡 `v-if="schoolIndicatorSummary.total > 0"`，snapshot 缺 `schoolIndicators`（旧 dist / 老数据）时直接隐藏
- 类型导出 `LocalSchoolIndicator` 是 re-export，不破坏原有引用

## 已知边界

- `school_indicators.csv` 只有 60 所学校（深广合计），分区城市间不平衡不显著，Top 5 主要反映**集团校头部集中度**
- 不与 `getSchoolDimensions()` 数据混合（来源 CSV 不同）；未来若想让 dashboard 同时显示 `LocalSchoolDimension`，可在 schoolIndicatorRanking 之外另起 derivedDimensions.ts
- 综合 ≥ 90 阈值沿用 v0.47.0 「重点高中大致阈值」经验值，未量化校准；如需动态阈值可后续接学校升学数据
