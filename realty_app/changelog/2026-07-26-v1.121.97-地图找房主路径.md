# v1.121.97 — 地图找房主路径（对照贝壳/链家）

## 问题

用户反馈：「地图找房」只有名字，不能像链家/贝壳那样真正找房。

## 对照

贝壳/链家地图找房闭环：筛总价/户型 → 点小区气泡 → 底栏房源列表 → 点进详情。

## 改动

- 默认图层改为「找房」（`listings`）
- 总价 / 户型快筛（`mapFind.ts`），联动 marker 与热力覆盖
- 点小区（气泡 / 地图最近点 / 聚合）→ 找房底栏列挂牌
- 点单套 marker / 底栏行 → `listing-detail`
- 「本小区全部房源」→ `listing-filter?communityId=`
- 验收：`MAP_ACCEPTANCE` F-MAP-04；`mapFind.test.ts`；`smoke_map_find.mjs`
