# v1.123.31 E2E flake 根治：networkidle 清退 + 默认端口统一

## 背景

v1.123.29 那轮 `run_suite extended` **首跑 6/9**——`smoke_community_metrics` / `smoke_school_community` / `smoke_data_tools_nav` 三例全部停在 `page.goto(..., { waitUntil: "networkidle" })` 超时，立即复跑却 9/9 全过。这不是功能回归，而是 v1.123.12 只加固了 2 个脚本、其余 7 个 extended 脚本仍用 `networkidle` 的遗留问题：uni-app H5 的挂起请求 / 慢资源会让「网络空闲」永远等不到，且它只覆盖网络层，不保证应用已渲染。

同时 `smoke_community_metrics.mjs` 单独运行默认 `5174→5175` 中的 5175 是死端口（与 v1.123.1 遗留的缺省值一致），单跑必然 `ERR_CONNECTION_REFUSED`；全仓另有 8 个脚本仍是 5175 缺省。

## 改动

**A. networkidle 全面清退（extended 7 个 + v093_097 4 个 = 11 个脚本）**

- `extended`（本轮复现的 3 个 + 同组其余）：
  - `smoke_community_metrics`：两处 goto → `domcontentloaded`；固定 3.5s sleep → 条件等待（标题可见 + `.cm-cell` 数量 = 5）
  - `smoke_school_community`：两处 reload + 首页 goto → `domcontentloaded`
  - `smoke_data_tools_nav`：reload + 首页 goto → `domcontentloaded`
  - `smoke_metro_walk`、`smoke_wangqian_heatmap`：两处 reload + 首页 goto → `domcontentloaded`
  - `smoke_cluster`：两处 goto/reload → `domcontentloaded`；固定 3.5s sleep → `.map-mode-btn[data-map-mode="price"]` 可见等待
  - `smoke_stats70_filter`：goto → `domcontentloaded`（首行渲染已有显式等待兜底）
  - `smoke_listing_minidim` / `smoke_metro_benefit`：v1.123.12 已加固，不动
- `v093_097` 组：`smoke_v093` / `smoke_v094` / `smoke_v095` / `smoke_v097` 的 goto 全部改 `domcontentloaded`（原有的 `waitForTimeout` 兜底保留）
- core 组 13 个脚本本就不含 networkidle，零改动

**B. 默认端口 5175 → 5174（10 个脚本）**

`community_metrics` / `bedroom_area` / `decorate_age` / `district_meta` / `feature_premium` / `listing_freshness` / `map` / `orientation_floor` / `scatter` / `tag_combination`。`REALTY_E2E_BASE_URL` 覆盖逻辑不变，只会让单跑默认值指向真实 serve 端口。

**C. 连带修复 v093_097 组的 3 个 stale 脚本（真实验证时暴露）**

首跑 `v093_097` 只过 2/5，排查确认不是等待策略问题，而是脚本目标早已迁移/退役：
- `smoke_v093` / `smoke_v094` 找的「分区近 12 周均价变动」「学校指标」卡在 v1.121.140/142 已迁至 `data-tools`，脚本仍打 dashboard → 改址 `data-tools` + 显式等待卡片 `.card-title`
- `smoke_v096` 断言的「三市标签横评」卡在 v1.123.29 已随 tag-penetration 体系删除，全仓零残留 → **脚本删除**，`run_suite` 的 `v093_097` 组由 5 → 4 个成员

**D. 防回归门禁（`tests/buildIntegrity.test.ts`）**

新增「E2E suite 脚本契约 v1.123.31」describe：自动从 `run_suite.mjs` 抽出成员脚本，断言 ①三个组共 26 个脚本；②任一脚本不得再出现 `waitUntil: "networkidle"`；③任一脚本不得出现 `http://127.0.0.1:5175` 字面量。
