## 一、改了什么（按用户反馈编号）

### 反馈 1：浅色模式「只有导航栏变白、内容不变」→ 根因修复 ✅

**根因**：App(app-plus) 页面 JS 跑在**逻辑层**，`theme.ts::paintDom` 用
`document.querySelectorAll("page,…")` 写属性/内联 CSS 变量，逻辑层拿不到真正渲染
页面的 WebView DOM → 只有 `paintChrome`（`uni.setNavigationBarColor`/`setTabBarStyle`
走 uni API）生效 → 导航栏/TabBar 变、内容不变。与反馈完全吻合。

**修复**：页面内容换肤主路径改为 **Vue 响应式属性绑定**（跨逻辑层→渲染层可靠）：

- `theme.ts` 新增导出 `resolvedThemeRef`（`ref<ResolvedTheme>`），`applyTheme` 内
  `resolvedThemeRef.value = resolved` 同步更新。
- 全部 19 个页面根节点绑定
  `:data-realty-theme="realtyTheme" :class="'realty-theme-' + realtyTheme"`。
- `App.vue` 新增**通用属性选择器** `[data-realty-theme="light"|"dark"] { --color-*: … }`，
  让浅/深变量从 `.page` 根**级联**到全部子内容；`.page[data-realty-theme]` 补底色。
- H5 仍保留 `paintDom` 双保险；原生壳 `paintChrome` 不变。

### 反馈 4：房源详情参考页直呼链家/贝壳 App（不再只跳浏览器）✅

**根因**：`plus.runtime.openURL("intent://…")` 把 `intent://` 当未知 scheme——只有
浏览器解析 intent://，所以真机「只能跳浏览器」。

**修复**：`openExternal.ts` 新增原生 Intent 唤起（`plus.android`）：
`launchAndroidAppForUrl`（ACTION_VIEW + setData(https) + setPackage(pkg) + startActivity）
与 `launchAndroidScheme`（自定义 scheme）。`openHousingSourceUrl` 先走原生
startActivity（贝壳/链家/安居客），失败再回退 `plus.runtime.openURL` deep link 链，
再回退浏览器/复制。H5/无 `plus.android`（含单测）行为不变。
listing-detail 已走 `openHousingSourceUrl`，自动获益。

### 反馈 2：右侧进度条移除 + 概览页长度收敛 ✅

- dashboard 移除 `<ScrollProgress />` 组件接入与 onPageScroll 采集逻辑（进度条从 UI 彻底消失）。
- 概览页压缩：对关键“大卡”调整 `data-tab`（剔除 `all/*` 混入概览），并在 `概览` 的精简模式下用 `isOverviewCompact` 门禁隐藏 nbsMacro 额外 KPI 与部分供需/土地大卡，避免默认信息流超过目标长度。
- 测试：新增 `tests/dashboardOverviewDataTabBudget.test.ts` + 更新 `tests/buildIntegrity.test.ts`，确保关键卡片 data-tab 配置不会回滚。

### 反馈 3 / 5：房源数据完善 / 整体过一遍 —— 本轮未做（见「未完成」）
