# 2026-07-27 v1.121.138 wgt 热更新打包修复

## 问题

github action / 本地 HBuilderX 打 wgt 失败, build:app 报 3 类错误阻断编译。

## 根因 + 修复

### 1. dashboard.vue (313:94) Duplicate attribute

**根因**: Batch 9 (v1.121.148) 加 ✕ 隐藏按钮时, 合并 v-if 不完整, 留下 2 张卡的 `<view>` 有 2 个 v-if 属性:
- L323: stats70-drift
- L435: lpr-mortgage-signal

Vue 3 不支持同标签多 v-if, build 阶段直接报错。

**修复**: 合并为 `v-if="!isCardHidden('xxx') && condition"` 单条件。

### 2. data-tools.vue (3:5) Element is missing end tag

**根因**: Batch 5 迁 metroPlan 卡片时只迁了部分, 留下 5 处模板不闭合:
- L639/L970: 2 个 `<br>` 写成了 void element, 但 vue 不接受非自闭 `<br>`
- L1072: 多 1 个 `</view>` (孤儿, 缩进错误)
- L1271: `<view v-for class="mp-row">` 跨行开始但没 `</view>` 关闭
- 缺首尾 view 关闭

**修复**:
- `<br>` → `<br/>`
- L1072 多余 `</view>` 删除
- L1271 v-for 补完整内容 (`mp-row` / `mp-rank` / `mp-mid` / `mp-line` / `mp-meta`) + 加 `</view>`
- 末尾 "剩余派生数据" 提示更新为 14/14 100% (Batch 1-5 全完成)

### 3. dashboard.vue (2014:63) expected "{"

**根因**: v0.40.0 (commit 4c7e158) 引入的 `.tc-bar { background: linear-gradient(90deg, #a78bfa 0%, #7c3aed 100%); ... }`, 在更早的 dead-css 清理脚本中被误删 selector, 留下孤儿 CSS rule `{ background: ...; border-radius: 6rpx; }`, SCSS 编译失败。

**修复**: 补回 `.tc-bar` selector。

### 4. 附 map-analysis.vue type-check 修复

**根因**: Batch 14 创建 map-analysis 时误以为 `DistrictMarker` 有 `districtName / avgUnitPrice / schoolScore / avgMetroMin` 字段, 实际只有 `district / lat / lng / communityId / communityName`。

**修复**: 改用 dashboard 同样的聚合算法 (`store.getListingsByCity + store.getListingSchoolPremiumByCity`), 不再读 marker 上不存在的字段。
