# v1.123.7（versionCode 342）· 旧专业 Tab 残余清零（data-tab 死属性 + 孤儿 ref）

日期：2026-11-03

## 背景

v1.123.6 删除旧 Dashboard 专业 Tab（F-DASH-04）全部实现后，留下三类残余：
遗留长卡与数据工具页上的 `data-tab` 死属性（消费者 CSS/JS 已删净）、
模板无任何消费的 `filterWorkbenchExpanded` ref，以及 `homeEntry.ts` 中
没有任何金刚/频道数据项使用的 `{ kind: "period" }` 动作变体。本轮清零。

## 变更

### dashboard.vue

- 模板：剥离全部 37 处 `data-tab="..."` 死属性（含 home-entry-card /
  nbsMacro / 各遗留长卡；纯属性删除，卡片显隐由 v122 壳层 CSS 决定，行为不变）。
- 脚本：删孤儿 `filterWorkbenchExpanded`（L5702 定义 + onHomeKingkong
  `period` 分支内赋值）；`period` 分支因无任何 `HOME_KINGKONG` 项使用
  `kind: "period"`，整支删除。

### homeEntry.ts

- `HomeKingkongAction` 联合类型删 `{ kind: "period" }` 变体（无数据项产生，
  类型层面封死死分支回潮）。

### data-tools.vue

- 剥离 11 处迁移时从 dashboard 卡复制来的 `data-tab="all,*"` 死属性
  （本页无 Tab 机制，无 CSS/JS 消费）。

  「各卡须按 tab 配置 data-tab」已随机制删除而失效，参考上轮
  `dashboardTabs.test.ts` 处理方式）。
