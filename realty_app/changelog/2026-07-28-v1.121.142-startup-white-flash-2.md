# 2026-07-28 v1.121.142 启动上半截白闪二修

**versionName**：1.121.142 · **versionCode**：263

## 诚实说明

v1.121.141 只靠单测推断「系统 theme 未就绪兜底浅色」，**没有真机验证启动首帧**。用户反馈仍必现后，重新对照首屏模板，定位到更直接的原因。

## 真因（可复现路径）

1. `dashboard.vue` 中 `showGuide = ref(true)`，首帧**一定**画出「首页使用指南」
2. `.home-guide-card` 写死浅色渐变 `#f0f4ff → #fef3c7`（近白/米黄）
3. `onMounted` 里才 `loadGuideDismissed()`：若用户已关闭过指南，第二帧立刻藏掉  
→ 启动页关掉后：**上半截先白一下再恢复深色**，必现

这与「浅色模式改造后更明显」也吻合：内容层换肤后深色底更干净，浅色指南卡对比更刺眼。

## 修复

| 项 | 做法 |
|----|------|
| 指南首帧 | `showGuide = ref(shouldShowDashboardGuide())` 同步读 storage |
| 指南样式 | 默认深色半透明渐变；仅 `data-realty-theme=light` 用浅色渐变 |
| 原生壳 | `pages.json` globalStyle 硬编码 `#0b1020/#080d18`；`setStatusBarBackground` + WebView `background` |
| setUIStyle | 跟随系统时按已解析主题设 dark/light，不再冷启动 `auto` |
| 门禁 | `tests/dashboardGuideFlash.test.ts` 锁住首帧初始化与默认样式 |
