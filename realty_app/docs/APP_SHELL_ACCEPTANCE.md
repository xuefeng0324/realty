# App 五栏壳层与本地资料库验收标准

> 功能 ID：`F-ENTRY-02` / `F-MKT-01` / `F-MINE-01`<br>
> 适用版本：`1.122.0`
> 总则：[FEATURE_QA_PROCESS.md](./FEATURE_QA_PROCESS.md)

## 1. 一级入口

原生 TabBar 固定为：**首页 / 找房 / 地图 / 行情 / 我的**。

| 入口 | Tab 路由 | 核心职责 |
|------|----------|----------|
| 首页 | `pages/dashboard/dashboard` | 城市、核心市场脉搏、快捷入口、推荐房源 |
| 找房 | `pages/listing-filter/listing-filter` | 房源 / 小区 / 学校三类检索与筛选 |
| 地图 | `pages/map-view/map-view` | 地图找房、行政区与社区图层 |
| 行情 | `pages/market/market` | 网签、70 城、供需、宏观、趋势和工具聚合 |
| 我的 | `pages/settings/settings` | 本地收藏、浏览历史、外观、数据与关于 |

**期望**

1. （功能）五个 Tab 均可用 `switchTab` 到达，非 Tab 页继续使用 `navigateTo`。
2. （逻辑）学校移出原生 Tab 后，旧学校深链仍可打开；应用内学校主入口统一从找房进入。
3. （UI）浅色、深色均使用统一翡翠绿主色和科技蓝信息色；320/390/768 宽度无横向溢出。
4. （UI）所有页面具备 loading / empty / error；联网页另覆盖 offline / stale / refreshing。

**不期望**

- 自绘一套与原生 TabBar 重叠的底栏。
- 对 Tab 页调用 `navigateTo`，或对详情页调用 `switchTab`。
- 首页继续堆叠全部专业分析卡，导致核心入口不可见。

## 2. 行情聚合

`pages/market/market` 只做可信入口与摘要，不复制完整子页。

**期望**

1. 网签、70 城、供需、5 个宏观页、趋势分析、数据工具均有明确入口。
2. 摘要显示来源和更新时间，明确区分真实数据与推导指标。
3. 旧首页移出的能力必须能在行情、宏观或数据工具中找到；映射表有单测。

**不期望**：把指数写成元/㎡、把挂牌写成成交价、用虚构 KPI 填空。

## 3. 我的：本地收藏与浏览历史

资料库仅保存在本机，不需要账号，不承诺跨设备同步。

**期望**

1. 支持房源、小区、学校收藏，以 `type:id` 去重。
2. 详情成功加载后写入浏览历史；无效 ID、加载失败不写入。
3. 历史按最近访问排序，最多 100 条、最多 90 天；重复访问更新时间而不是新增重复行。
4. storage 损坏或未知版本时安全回空，不阻塞 App 启动。
5. “我的”明确显示“仅本机”，可打开收藏/历史条目并可清空历史。

**不期望**：保存完整业务响应、记录错误页、暗示云同步、跨城市串条目。

## 4. 自动化与手工验收

- unit：`navigation.test.ts`、`userLibrary.test.ts`、主题与页面映射测试。
- core smoke：五栏跳转、收藏闭环、22 路由、320/390/768、浅/深主题。
- 真机：Android 五栏主题同步；地图原生层不遮挡结果 Sheet；详情页返回路径正确。

手工最短路径：

1. 依次点击五个 Tab，核对标题和高亮。
2. 找房筛选后进入详情，收藏并返回“我的”。
3. 从收藏重新打开详情，取消收藏；浏览历史仍保留且无重复。
4. 切换浅色、深色、跟随系统，在首页/地图/行情/我的各检查一次。
