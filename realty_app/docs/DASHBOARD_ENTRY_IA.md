# 总览多入口信息架构（Dashboard Entry IA）

> 功能 ID：**F-ENTRY-01**（历史）/ **F-ENTRY-02**（v1.122.0 五栏）<br>
> 对照来源：美团/淘宝/拼多多首页（定位+搜索+频道+金刚区+信息流）；贝壳/链家（城市+找房入口）；本仓房价三轴与 `DATA_SOURCES.md`。  
> 流程：遵循 [FEATURE_QA_PROCESS.md](./FEATURE_QA_PROCESS.md)。

---

## 1. 问题

旧总览首屏以「筛选工作台 + 长卡片流」为主，入口过单：

- 搜索缺失，跨页跳转依赖 TabBar 记忆
- 快捷入口埋在页中部（`hero`/`quick-grid`），首屏看不见
- 官方宏观 / 网签 / 70城 / 库存等数据没有统一「频道」语义

---

## 2. 目标 IA（借鉴大厂，贴合本产品）

### v1.122.0 一级入口

原生底栏固定为“首页 / 找房 / 地图 / 行情 / 我的”。首页保留城市、搜索、核心指标、快捷入口与推荐房源；原先专业频道和长卡流迁入行情、宏观或数据工具。找房统一承载房源、小区、学校入口。完整契约见 [APP_SHELL_ACCEPTANCE.md](./APP_SHELL_ACCEPTANCE.md)。

```text
┌─────────────────────────────────────────┐
│ [城市▾]  [⌕ 搜学校 / 房源 / 本页关键词]   │  ← 美团定位 + 淘宝搜索
├─────────────────────────────────────────┤
│ 房价 · 网签 · 宏观 · 供需 · 配套 · 工具   │  ← 拼多多/淘宝频道条
├─────────────────────────────────────────┤
│  房源 学校 地图 网签 70城                 │  ← 金刚区（2×5）
│  宏观 库存 土地 价格 学区                 │
├─────────────────────────────────────────┤
│ 今日要点 / 70城卡 / 官方宏观 / …信息流    │
└─────────────────────────────────────────┘
```

| 层 | 职责 | 不做什么 |
|----|------|----------|
| 定位 | 切换城市 | 不伪造成交价 |
| 搜索 | 学校关键字 / 房源关键字 / 本页锚点 | 不做未经验证的「智能均价」 |
| 频道 | 一键进入对应独立页 / Tab（房价·网签·宏观·供需·配套·工具） | 不新增第三方源；**禁止**只滚本页长流 |
| 金刚区 | 高频页面与数据入口（含供需页） | 不替代 TabBar；库存/土地不滚锚点 |
| 工作台 | 高级周次/来源/指标（默认折叠） | 不再霸占首屏 |

## 3. 验收标准（UI / 功能 / 逻辑）

### UI

| 期望 | 不期望 |
|------|--------|
| 首屏可见：城市芯片 + 搜索框 + 频道条 + 金刚区 | 首屏只有筛选表单、无搜索 |
| 金刚区 ≥ 8 个入口，文案可读、触控热区足够 | 入口图标挤在页中部才出现 |
| 浅/深色下搜索框与频道对比度可读 | 紫渐变花哨皮肤、难读占位符 |

### 功能

| 期望 | 不期望 |
|------|--------|
| 点城市芯片 → 弹出城市选择 | 点了无反馈 |
| 搜索模式「学校」+ 关键字确认 → 写入 pending query 并 `switchTab` 学校页自动检索 | 学校页忽略 pending query |
| 搜索模式「房源」+ 关键字 → pending listing query + `switchTab` 房源页自动筛选；无关键字仅切 Tab | navigateTo 打到 TabBar 页失败；有关键字却全量不筛 |
| 频道「宏观」→ `navigateTo` 宏观区域页；「供需」→ 供需页；「工具」→ 数据工具页 | 只滚到本页卡片 |
| 金刚「网签」「70城」「库存」「土地」→ 对应子页 | 空跳转；库存/土地本页 scrollIntoView |

### 逻辑

| 期望 | 不期望 |
|------|--------|
| 入口配置集中在 `homeEntry.ts`，单测覆盖路由解析 | 硬编码散落且无门禁 |
| 入口文案不出现「成交均价」误标 | 把挂牌/指数写成成交价 |
| 本页关键词映射（宏观/网签/库存…）可测 | 随意字符串导致白屏 |

## 4. 测试流程

```text
L0  npm run type-check
L1  npm test -- tests/homeEntry.test.ts tests/uiDesign.test.ts
L2  （可选）H5：首屏截图核对搜索+金刚；点 70城/网签/学校
L3  真机：TabBar 跳转房源/学校/地图；搜索学校带 q；搜索房源带关键字自动筛选
```

手工最短路径：

1. 打开总览 → 见搜索与金刚区  
2. 城市芯片切换广州/深圳 → 今日要点城市名变化  
3. 搜索模式「学校」，输入「实验」→ 学校页有结果或空态文案  
4. 频道「宏观」→ 进入宏观区域独立页（非本页滚动）  
5. 频道「供需」/ 金刚「库存」→ `/pages/supply/supply`  
6. 频道「工具」→ `/pages/data-tools/data-tools`  
7. 金刚「网签」→ 政府每日网签页
