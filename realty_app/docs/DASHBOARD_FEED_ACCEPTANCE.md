# 首页信息流连续性验收标准

> 流程总则：[FEATURE_ACCEPTANCE.md](./FEATURE_ACCEPTANCE.md)  
> 对照：
> - [Material Design 3 — Lists / Surface](https://m3.material.io/components/lists/overview)（列表项用 outline 细分隔，避免大块 gutter）
> - 贝壳找房 / 链家 App 首页信息流：同色表面连续滚动，块与块之间不是「另一条背景色沟」
> - uni-ui `uni-list` 惯例：项间为细分割线，而非大 margin 露底

## 1. 问题定义

历史总览（dashboard）为超长滚动页。旧样式每个 `.card` 有：

- `margin-bottom: 24rpx`
- 独立 `box-shadow` + 圆角边框
- 页面底色 / 径向渐变与卡片表面色差大

滚动时，卡片之间的**页面底色条带**看起来像「每一整屏背景被分割线切开」，观感差。

v1.122.0 首页已收敛为品牌 Hero、市场脉搏、五入口、推荐内容和数据口径五段，不再用旧 `.container > .card` 结构做验收。

## 2. 方案（仅首页）

| 做 | 不做 |
|----|------|
| 仅 `dashboard` 页：五段内容使用统一 `24rpx` 节奏 | 不改其它 Tab 页卡片体系 |
| 卡片表面、边框与阴影统一，Hero 保留品牌层级 | 不重新显示旧专业长卡流 |
| 320/390/768 均保证区块不溢出 | 不用负边距或裁切掩盖问题 |

## 3. 验收标准

### 期望

1. 首页五段可见内容间距一致，换算到 420px 视口不超过 16px
2. 每段都有可辨识表面或品牌渐变，不出现透明空洞
3. 每段左右边界均在首页壳层内，无横向溢出
4. 主题切换后（浅/深）仍满足 1–3  

### 不期望

1. 其它页面（房源/设置等）被连带改成「无 gutter」  
2. 用完全无间距的信息堆叠破坏章节层级
3. 为去缝引入新的强渐变条纹或横向裁切

### 自动化

- [x] `tests/e2e/smoke_dashboard_feed_seam.mjs`：明暗主题各检查 5 段、相邻间距 `≤16px`、表面非透明且不越过壳层
- [x] `npm run type-check` / `npm test` 通过

### 手工（H5 或真机）

1. 打开首页，慢滑至推荐内容与数据口径
2. 浅色、深色各滑一遍  
3. 通过：无明显「黑/灰宽缝」横切画面；失败则截图阻断发版
